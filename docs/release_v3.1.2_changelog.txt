## v3.1.2 更新日志

### 新功能

- **720p 转码系统**：新增统一调度器，支持转码中断智能恢复、分辨率标识增强、视频播放体验优化
- **Brouhaha SNR+C50 分诊**：集成三层分诊策略（SNR信噪比 + C50清晰度），使用本地离线模型
- **字幕准确率映射**：支持置信度到准确率的映射显示
- **编辑器优化**：优化保存提示交互

### 改进

- 统一 Whisper 模型校验逻辑，提升不同模型格式的兼容性与一致性
- 优化频谱分诊阈值配置，提高音频质量判断准确性
- 优化人声分离后的音频处理流程，提升能量检测及归一化准确性

### 修复

- 修复任务删除时因文件占用导致删除失败的问题，新增占用检测与延迟删除机制
- 修复置信度徽章在特定条件下显示误导信息的问题

## v3.1.2 Changelog

### New Features

- **720p HD Transcoding System**: Added unified scheduler with intelligent interrupt recovery, enhanced resolution indicators, and improved video playback fallback experience
- **Brouhaha SNR+C50 Triage**: Integrated three-layer triage strategy (SNR + C50 clarity), supporting local offline model loading
- **Smart Probe Triage**: Added probe mode and progress bar support for triage and separation stages, significantly improving processing efficiency
- **Subtitle Accuracy Mapping**: Added confidence-to-accuracy mapping with full frontend-backend data integration
- **Editor Enhancements**: Improved save prompt interaction and Chinese text highlighting

### Improvements

- Unified Whisper model validation logic for better compatibility across different model formats
- Optimized spectral triage threshold configuration for improved audio quality assessment
- Enhanced post-separation audio processing with improved energy detection and normalization accuracy

### Bug Fixes

- Fixed task deletion failures caused by file locks, added file occupation detection and delayed deletion mechanism
- Fixed misleading confidence badge display under specific conditions
