## 1. 核心设计理念

### 1.1 架构原则：左移与解耦 (Shift Left & Decoupling)

为了保证后端核心转录工作流（Workers）的高效与纯粹，我们将所有的“元数据分析”工作（语种检测、声纹提取）从转录阶段**前置**到预处理阶段（Preprocessing Pipeline）。

* **AOT (Ahead-Of-Time) 分析**：在生成 Task 放入队列之前，AudioChunk 必须已经携带了准确的 `language` 标签和 `speaker_embedding` 向量。
* **状态无感**：FastWorker 和 SlowWorker 不再进行任何逻辑判断，只负责执行 Task 中指定的参数。

### 1.2 技术选型：SpeechBrain 生态

采用 **SpeechBrain** 框架统一解决 LID 和 声纹问题，利用其共享的 ECAPA-TDNN 架构实现依赖最小化。

* **LID 模型**：`speechbrain/lang-id-voxlingua107-ecapa`
* *优势*：针对 YouTube 真实视频数据训练，抗噪性强，支持 107 种语言（含中日韩英）。


* **声纹模型**：`speechbrain/spkrec-ecapa-voxceleb`
* *优势*：轻量级，提取速度快，与 LID 共享底层依赖。

## 2. 多语言检测策略 (LID Strategies)

为了在“极速预览”和“精准识别”之间取得平衡，系统实现三种可选模式。

### 2.1 基础优化技术 (应用于所有模式)

1. **Center Crop (中心裁剪)**：LID 不需要听完整个切片。对于任意长度 > 4s 的切片，仅截取**中间 4 秒**进行推理。这减少了 70%+ 的计算量。
2. **Matrix Batching (矩阵批处理)**：严禁串行循环。将裁剪后的 Tensor 通过 Padding 对齐，堆叠成大 Batch（如 size=32），一次性通过 CPU 推理。

### 逻辑分组 + 矩阵批处理

我们需要保持每个 Chunk 的**独立性**，但通过**并行计算**来提升速度。

#### 步骤一：逻辑分组 (Logical Grouping) - *为了决策策略*

这是我们之前提到的“智能模式（Mode 2）”。

我们不累积音频数据，而是累积**对象引用**。

- **操作**：创建一个列表，收集 0~60秒 内所有的 `AudioChunk` 对象。
- **目的**：为了决定哪些 Chunk 需要被当作“探针”送去检测。

#### 步骤二：数据预处理 (Center Crop) - *为了统一规格*

LID 模型（SpeechBrain）输入通常需要 Tensor 维度一致才能高效并行。

- **输入**：一堆长短不一的 Chunk（2s, 5s, 10s...）。
- **操作**：
  1. **大于 4s 的**：只取中间 4秒（截断）。
  2. **小于 4s 的**：保持原样。
- **结果**：所有待检测的数据都被限制在 $\le 4s$ 的范围内。

#### 步骤三：物理打包 (Padding & Stacking) - *为了并行速度*

这是最核心的工程实现。我们需要把分散的 Chunk 变成一个 **Batch Tensor**。

- **问题**：Tensor 必须是矩形的，但 Chunk 长度不一（有的 2s，有的 4s）。
- **解决**：使用 **Padding（填充）**。
  - Chunk A (2s) -> 补 2s 静音 -> 变成 4s
  - Chunk B (4s) -> 不动 -> 4s
- **堆叠**：将它们堆叠成形状为 `(Batch_Size, Time_Steps)` 的大矩阵。

### 2.2 三种检测模式详解

#### 模式 A：极速模式 (Fast / Sparse Sampling)

* **适用场景**：绝大多数单语言视频（会议、演讲）。
* **算法逻辑**：
1. 全视频仅采样 **10-15 个** 切片（均匀分布）。
2. 如果 90% 的结果一致（Consensus > 0.9），则判定为单语言视频。
3. **广播标签**：将该主语言应用到所有 Task。


* **耗时**：< 0.5秒。

#### 模式 B：智能平衡模式 (Balanced / Adaptive Grouping) —— **推荐默认**

* **适用场景**：电影、Vlog、绝大部分未知视频。
* **算法逻辑 (时窗边界探测法)**：
1. **宏观分组**：按时间轴将切片划分为 **60秒** 的逻辑组（Decision Window）。
2. **五点探测**：对每组取 `[0%, 25%, 50%, 75%, 100%]` 处的 5 个切片作为探针。
3. **组内判决**：
* 若 5 点一致 -> 该组所有切片标记为该语言。
* 若不一致 -> **局部降级**：仅对该组触发“全量检测”。


4. **边界缝隙微扫 (Boundary Seam Micro-Scan)**：
* 若 `Group[i]` 为中文，`Group[i+1]` 为英文。
* **触发微扫**：对 `Group[i]` 的后 25% 和 `Group[i+1]` 的前 25% 进行全量检测，精修语言切换的精确边界。

#### 模式 C：精准模式 (Precise / Full Scan)

* **适用场景**：复杂的多语言访谈、强干扰环境、或用户强制指定。
* **算法逻辑**：
1. 对所有切片进行 Batch LID 推理。
2. 依然应用 Center Crop 优化，确保即使是全量检测也能在数秒内完成。

## 3. 声纹识别集成方案 (Speaker Diarization)

采用 **“预处理提取 -> 任务携带 -> 完结聚类”** 的三步走策略。

### 3.1 阶段一：特征提取 (Preprocessing Phase)

在 `PreprocessingPipeline` 中，与 LID 并行或串行执行。

* **开关控制**：仅在用户开启“区分说话人”或使用“精准模式”时运行。
* **动作**：调用 `spkrec-ecapa-voxceleb`，对全量切片提取 `192维` 浮点向量。
* **数据流**：向量不进行任何处理，直接写入 `Task` 对象。

### 3.2 阶段二：数据流转 (Task & Schema)

更新数据结构以支持携带元数据。

```python
class TranscriptionTask(BaseModel):
    chunk_index: int
    audio: Any
    language: str = "auto"          # 由 LID 填入
    speaker_embedding: Optional[List[float]] = None # 由声纹模型填入

```

### 3.3 阶段三：全局聚类 (Job Completion Phase)

在 `JobManager` 监测到任务所有切片完成后触发。

* **动作**：
1. 从数据库/内存拉取该 Job 所有切片的 Embedding。
2. 使用 `sklearn.cluster.AgglomerativeClustering` (层次聚类) 进行计算。
3. **Metric**：必须使用 `cosine` (余弦距离)。


* **绑定**：根据聚类结果（Labels），批量更新数据库中对应 Subtitle 的 `SpeakerID` 字段。

## 4. 核心服务代码实现概览

### 4.1 统一语音分析服务 (`SpeechAnalysisService`)

```python
class SpeechAnalysisService:
    def detect_balanced_strategy(self, chunks: List[AudioChunk]) -> Dict[int, str]:
        """模式 B：智能分组 + 边界微扫"""
        results = {}
        # 1. 分组 (60s)
        groups = self._group_by_time(chunks, 60)
        
        # 2. 收集所有探针 (Probes) 并行推理
        probes = self._collect_probes(groups)
        probe_results = self._infer_batch(probes) # Center Crop + Padding + Batch
        
        # 3. 组内广播
        for group in groups:
            if self._is_consistent(group, probe_results):
                self._broadcast(group, results)
            else:
                self._fallback_full_scan(group, results)
        
        # 4. 边界微扫
        self._refine_boundaries(groups, results)
        return results

    def extract_embeddings(self, chunks: List[AudioChunk]) -> Dict[int, List[float]]:
        """声纹提取：全量 Batch 推理"""
        # 使用 spkrec-ecapa-voxceleb
        # 必须全量，但可以使用 batch_size=64 加速
        return self._infer_embeddings_batch(chunks)

```

### 4.2 预处理管线集成 (`PreprocessingPipeline`)

```python
class PreprocessingPipeline:
    async def run(self, ...):
        # 1. VAD & Demucs
        chunks = ...
        
        # 2. 语言检测 (LID)
        if config.mode == "fast":
            lang_map = speech_service.detect_fast(chunks)
        elif config.mode == "precise":
            lang_map = speech_service.detect_full(chunks)
        else:
            lang_map = speech_service.detect_balanced_strategy(chunks) # 默认
            
        # 3. 声纹提取 (可选)
        emb_map = {}
        if config.enable_diarization:
            emb_map = speech_service.extract_embeddings(chunks)
            
        # 4. 任务生成
        for chunk in chunks:
            task = TranscriptionTask(
                ...,
                language=lang_map.get(chunk.index, "en"),
                speaker_embedding=emb_map.get(chunk.index)
            )
            queue.push(task)

```
