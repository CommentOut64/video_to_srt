# 同音检索与批量替换开发文档

> Type: Architecture | Status: Active
> 版本：V3.2.0+dev.20260210.03

## 1. Summary

* **Goal**：在现有编辑器字幕列表中实现“精确/正则/同音（严格/模糊）”统一查找与批量替换，支持超大文本高性能检索，并保证前后端可联通落地。
* **关键新增约束**：
  1. 支持全局专有名词表（所有任务共享），作为默认自动替换规则。
  2. 默认不支持跨字幕匹配（禁止跨 `sentence_index` 拼接匹配）。
  3. 支持“跨标点匹配”可选开关（仅单字幕内生效，默认关闭）。

## 2. Diagram

* 转录主链：`L4 -> L5 -> L6 -> L7(输出)`
* 同音索引构建：`L7输出成功 -> 异步侧车 index_chunk(job_id, chunk_index)`
* 用户查找：`前端模式单选 -> /homophone/find -> 返回命中字幕+高亮span`
* 用户替换：`前端勾选字幕 -> /homophone/batch-replace -> SSE/轮询回写`
* 全局术语自动替换：
  * 默认：`L7前同步替换（低延迟路径）`
  * 超阈值降级：`L7后异步补丁替换（避免阻塞推送）`

## 3. Key Components

* `backend/app/services/homophone/db.py`：SQLite 持久化、索引状态与术语表。
* `backend/app/services/homophone/tokenizers.py`：中/日/英词级切分与读音编码。
* `backend/app/services/homophone/service.py`：索引构建、查找、批量替换、全局术语替换。
* `backend/app/services/homophone/runtime.py`：同音服务单例、异步索引侧车编排。
* `backend/app/api/routes/transcription_routes.py`：同音查找/替换/术语表接口。
* `frontend/src/components/editor/SubtitleList/index.vue`：模式单选、搜索、勾选、批量替换。
* `frontend/src/components/editor/SubtitleList/SubtitleItem.vue`：匹配高亮与复选框。

## 4. 范围与边界

### 4.1 必做范围

1. 查找模式单选：
   * 文本精确
   * 正则
   * 同音严格
   * 同音模糊
   * 可选：忽略标点匹配（仅同音模式显示）
2. 批量替换支持：
   * 精确/正则
   * 同音严格/模糊
3. 批量选择：
   * 命中字幕默认全选
   * 单条可取消
   * 工具栏全选/取消全选
4. 全局专有名词表：
   * 设置页维护
   * 后端持久化
   * 所有任务共享
   * 默认自动替换

### 4.2 强约束（必须遵守）

1. **禁止跨字幕匹配**：
   * 仅在单条字幕 `sentence_index` 内匹配。
   * 不允许上一条尾部 + 下一条头部组合命中。
2. **全局术语替换不可静默破坏用户编辑**：
   * 若句子 `is_modified=True`，自动替换需跳过或仅提示。

## 5. 查询模式设计（前端单选，不走语法前缀）

## 5.1 交互定义

搜索框左侧使用单选按钮（Segmented Control）：

* `文本精确`：普通字符串匹配。
* `正则`：正则表达式匹配。
* `同音严格`：严格读音（中文可区分声调、日语可区分长音、英语可区分重音）。
* `同音模糊`：读音近似匹配（可配置阈值）。

### 5.2 多音输入支持（不让用户记语法）

在“同音”模式下，额外显示“读音输入框”（可选）：

* 中文：可输入 `zhong4`。
* 日语：可输入罗马音 `omoi`（后端转假名/读音key）。
* 英语：可输入近似音素文本（可选，默认文本->读音）。

若读音输入为空，则对文本做多读音扩展并按簇分组展示。

### 5.3 跨标点匹配（可选开关）

* 开关名：`忽略标点匹配`（`is_ignore_punctuation=true/false`）。
* 默认：`false`（保持严格匹配）。
* 打开后：
  * 仅在同一 `sentence_index` 内，忽略标点进行同音匹配。
  * 不改变“禁止跨字幕匹配”规则。
* 风险控制：
  * 该开关只影响查找召回范围。
  * 不自动删除、插入或重排标点。

## 6. 词级切分与读音策略（快 + 准）

## 6.1 总体原则

1. **索引构建阶段做重活**，查询阶段只查索引。
2. **词级优先，单字兜底**。
3. **每条字幕独立分词**，严格禁止跨字幕拼接。

## 6.2 语言策略

### 中文

* 分词：`pkuseg`（推荐）或 `jieba`（兼容）。
* 读音：`pypinyin + pypinyin-dict`。
* 多音字：词级优先消歧；保留 `alt_readings` 做候选簇。

### 日语

* 分词：`SudachiPy`（默认 `SplitMode.B`，必要时 `A` 兜底）。
* 读音：`reading_form()`。
* 罗马音输入：后端转换后统一到读音key。

### 英语

* 分词：正则词切分（保留 `'`）。
* 读音：`cmudict` 优先，OOV 回退 `phonemizer`。

### 7.1 不跨字幕匹配的数据库保障

* `homophone_postings` 的匹配粒度固定到 `(sentence_index, token_index)`。
* 不提供任何跨 `sentence_index` 的窗口查询 SQL。

```python
# backend/app/services/homophone/db.py
from __future__ import annotations

import sqlite3
from contextlib import contextmanager
from dataclasses import dataclass
from pathlib import Path
from typing import Iterable


@dataclass(frozen=True)
class DbConfig:
    db_path: Path


class HomophoneDb:
    def __init__(self, config: DbConfig) -> None:
        self._db_path = config.db_path
        self._db_path.parent.mkdir(parents=True, exist_ok=True)
        self._init_schema()

    @contextmanager
    def connect(self) -> sqlite3.Connection:
        conn = sqlite3.connect(str(self._db_path))
        conn.row_factory = sqlite3.Row
        conn.execute("PRAGMA journal_mode=WAL;")
        conn.execute("PRAGMA synchronous=NORMAL;")
        conn.execute("PRAGMA temp_store=MEMORY;")
        try:
            yield conn
            conn.commit()
        except Exception:
            conn.rollback()
            raise
        finally:
            conn.close()

    def _init_schema(self) -> None:
        sql_path = Path(__file__).with_name("schema.sql")
        if not sql_path.exists():
            return
        with self.connect() as conn:
            conn.executescript(sql_path.read_text(encoding="utf-8"))

    def upsert_state(
        self,
        *,
        job_id: str,
        revision: int,
        status: str,
        last_committed_chunk: int,
        heartbeat_at: str,
        updated_at: str,
    ) -> None:
        with self.connect() as conn:
            conn.execute(
                """
                INSERT INTO homophone_index_state
                (job_id, revision, status, last_committed_chunk, heartbeat_at, updated_at)
                VALUES (?, ?, ?, ?, ?, ?)
                ON CONFLICT(job_id, revision) DO UPDATE SET
                  status=excluded.status,
                  last_committed_chunk=excluded.last_committed_chunk,
                  heartbeat_at=excluded.heartbeat_at,
                  updated_at=excluded.updated_at
                """,
                (job_id, revision, status, last_committed_chunk, heartbeat_at, updated_at),
            )

    def replace_chunk_postings(
        self,
        *,
        job_id: str,
        revision: int,
        chunk_index: int,
        rows: Iterable[tuple],
    ) -> None:
        with self.connect() as conn:
            conn.execute(
                """
                DELETE FROM homophone_postings
                WHERE job_id=? AND revision=? AND chunk_index=?
                """,
                (job_id, revision, chunk_index),
            )
            conn.executemany(
                """
                INSERT INTO homophone_postings(
                  job_id, revision, language, chunk_index, sentence_index, token_index,
                  token_text, reading_key, reading_key_fuzzy,
                  reading_key_no_punct, reading_key_fuzzy_no_punct,
                  char_start, char_end
                ) VALUES (?, ?, ?, ?, ?, ?, ?, ?, ?, ?, ?, ?, ?)
                """,
                rows,
            )
```

## 8.2 分词与读音层 `tokenizers.py`

```python
# backend/app/services/homophone/tokenizers.py
from __future__ import annotations

from dataclasses import dataclass
from typing import List, Protocol
import re

from pypinyin import Style, pinyin
from sudachipy import dictionary, tokenizer


@dataclass(frozen=True)
class TokenReading:
    token_text: str
    reading_key: str
    reading_key_fuzzy: str
    reading_key_no_punct: str
    reading_key_fuzzy_no_punct: str
    char_start: int
    char_end: int


class ReadingTokenizer(Protocol):
    def tokenize(self, text: str) -> List[TokenReading]:
        ...


class ZhTokenizer:
    """中文词级分词 + 拼音编码（词级优先）。"""

    def tokenize(self, text: str) -> List[TokenReading]:
        # 为示例简化：实际接 pkuseg/jieba 并拿词边界
        # 这里退化为逐字，生产实现需替换为词级分词器
        rows: List[TokenReading] = []
        cursor = 0
        for char in text:
            py = pinyin(char, style=Style.TONE3, heteronym=False)
            strict = py[0][0] if py and py[0] else char
            fuzzy = re.sub(r"[1-5]$", "", strict)
            rows.append(
                TokenReading(
                    token_text=char,
                    reading_key=strict,
                    reading_key_fuzzy=fuzzy,
                    reading_key_no_punct=strict if re.search(r"\w", char) else "",
                    reading_key_fuzzy_no_punct=fuzzy if re.search(r"\w", char) else "",
                    char_start=cursor,
                    char_end=cursor + len(char),
                )
            )
            cursor += len(char)
        return rows


class JaTokenizer:
    def __init__(self) -> None:
        self._tokenizer = dictionary.Dictionary().create()

    def tokenize(self, text: str) -> List[TokenReading]:
        rows: List[TokenReading] = []
        cursor = 0
        for t in self._tokenizer.tokenize(text, tokenizer.Tokenizer.SplitMode.B):
            surface = t.surface()
            reading = t.reading_form() or surface
            fuzzy = reading.replace("ー", "")
            rows.append(
                TokenReading(
                    token_text=surface,
                    reading_key=reading,
                    reading_key_fuzzy=fuzzy,
                    reading_key_no_punct=reading if re.search(r"\w", surface) else "",
                    reading_key_fuzzy_no_punct=fuzzy if re.search(r"\w", surface) else "",
                    char_start=cursor,
                    char_end=cursor + len(surface),
                )
            )
            cursor += len(surface)
        return rows


class EnTokenizer:
    _word_re = re.compile(r"[A-Za-z']+")

    def tokenize(self, text: str) -> List[TokenReading]:
        rows: List[TokenReading] = []
        for m in self._word_re.finditer(text):
            token = m.group(0)
            strict = token.lower()  # 示例：生产中替换为 cmudict/phonemizer 结果
            fuzzy = strict
            rows.append(
                TokenReading(
                    token_text=token,
                    reading_key=strict,
                    reading_key_fuzzy=fuzzy,
                    reading_key_no_punct=strict,
                    reading_key_fuzzy_no_punct=fuzzy,
                    char_start=m.start(),
                    char_end=m.end(),
                )
            )
        return rows
```

## 8.3 业务层 `service.py`

```python
# backend/app/services/homophone/service.py
from __future__ import annotations

from dataclasses import dataclass
from datetime import datetime, timezone
from typing import Any, Dict, List, Literal

from .db import HomophoneDb
from .tokenizers import EnTokenizer, JaTokenizer, ZhTokenizer, TokenReading

Language = Literal["zh", "ja", "en"]
SearchMode = Literal["literal", "regex", "homophone_strict", "homophone_fuzzy"]


@dataclass(frozen=True)
class MatchSpan:
    sentence_index: int
    char_start: int
    char_end: int
    token_text: str
    reading_key: str


class HomophoneService:
    def __init__(self, db: HomophoneDb) -> None:
        self._db = db
        self._zh = ZhTokenizer()
        self._ja = JaTokenizer()
        self._en = EnTokenizer()

    def _tokenizer(self, language: Language):
        if language == "zh":
            return self._zh
        if language == "ja":
            return self._ja
        return self._en

    def index_chunk(
        self,
        *,
        job_id: str,
        revision: int,
        chunk_index: int,
        language: Language,
        sentences: List[Dict[str, Any]],
    ) -> None:
        """按 chunk 增量构建索引；严格不跨字幕。"""
        now = datetime.now(timezone.utc).isoformat()
        self._db.upsert_state(
            job_id=job_id,
            revision=revision,
            status="building",
            last_committed_chunk=max(-1, chunk_index - 1),
            heartbeat_at=now,
            updated_at=now,
        )

        rows: List[tuple] = []
        tokenizer = self._tokenizer(language)
        for sentence in sentences:
            sentence_index = int(sentence["index"])
            text = str(sentence.get("text") or "")
            tokens: List[TokenReading] = tokenizer.tokenize(text)
            for token_index, token in enumerate(tokens):
                rows.append(
                    (
                        job_id,
                        revision,
                        language,
                        chunk_index,
                        sentence_index,
                        token_index,
                        token.token_text,
                        token.reading_key,
                        token.reading_key_fuzzy,
                        token.reading_key_no_punct,
                        token.reading_key_fuzzy_no_punct,
                        token.char_start,
                        token.char_end,
                    )
                )

        self._db.replace_chunk_postings(
            job_id=job_id,
            revision=revision,
            chunk_index=chunk_index,
            rows=rows,
        )

        now2 = datetime.now(timezone.utc).isoformat()
        self._db.upsert_state(
            job_id=job_id,
            revision=revision,
            status="ready",
            last_committed_chunk=chunk_index,
            heartbeat_at=now2,
            updated_at=now2,
        )

    def search_homophone(
        self,
        *,
        job_id: str,
        revision: int,
        language: Language,
        query_reading_key: str,
        is_fuzzy: bool,
        is_ignore_punctuation: bool,
        limit: int = 500,
    ) -> List[MatchSpan]:
        if is_ignore_punctuation:
            key_column = "reading_key_fuzzy_no_punct" if is_fuzzy else "reading_key_no_punct"
        else:
            key_column = "reading_key_fuzzy" if is_fuzzy else "reading_key"
        sql = f"""
            SELECT sentence_index, char_start, char_end, token_text, reading_key
            FROM homophone_postings
            WHERE job_id=? AND revision=? AND language=? AND {key_column}=?
            ORDER BY sentence_index, token_index
            LIMIT ?
        """
        with self._db.connect() as conn:
            rows = conn.execute(
                sql,
                (job_id, revision, language, query_reading_key, limit),
            ).fetchall()
        return [
            MatchSpan(
                sentence_index=int(r["sentence_index"]),
                char_start=int(r["char_start"]),
                char_end=int(r["char_end"]),
                token_text=str(r["token_text"]),
                reading_key=str(r["reading_key"]),
            )
            for r in rows
        ]
```

## 8.4 全局专有名词表自动替换（关键逻辑）

```python
# backend/app/services/homophone/global_terms.py
from __future__ import annotations

from dataclasses import dataclass
from typing import List


@dataclass(frozen=True)
class GlobalTermRule:
    language: str
    source_text: str
    target_text: str
    priority: int


def apply_global_terms_to_sentence(
    *,
    text: str,
    language: str,
    rules: List[GlobalTermRule],
) -> str:
    """默认同步替换：只在单条字幕内替换，不跨字幕。"""
    sorted_rules = sorted(
        [r for r in rules if r.language in (language, "auto")],
        key=lambda x: (x.priority, -len(x.source_text)),
    )
    output = text
    for rule in sorted_rules:
        if not rule.source_text:
            continue
        output = output.replace(rule.source_text, rule.target_text)
    return output
```

### 8.4.1 替换时机决策

* 默认策略：**L7 前同步替换**（避免二次推送闪烁）。
* 降级策略：
  * 当术语规则数过大（如 > 5000）或 chunk 字符数过大（如 > 4000）时，
  * 切到 `L7后异步替换补丁`，并通过 `subtitle.edited` 增量回写。

## 9.3 同音严格返回字段（支持前端分组）

同音严格/同音模糊模式建议在 `matches[]` 中返回以下字段：

* `sentence_index`：命中字幕索引。
* `start` / `end`：字幕时间（用于时间排序）。
* `char_start` / `char_end`：高亮位置。
* `reading_key`：读音键（如 `zhong4`）。
* `reading_label`：展示名（如 `zhong4 / 中-第四声`）。
* `cluster_id`：读音簇ID（前端颜色与分组依据）。

说明：

* 前端两种排序模式均依赖 `cluster_id`。
* 若后端未返回 `cluster_id`，前端可临时使用 `reading_key` 作为簇ID。

## 10.2 搜索与默认勾选

```javascript
async function executeSearch() {
  if (!searchText.value && !searchReading.value) {
    matchedSubtitleIds.value = new Set()
    selectedSubtitleIds.value = new Set()
    matchSpansMap.value = new Map()
    return
  }

  const resp = await transcriptionApi.findHomophone(projectStore.meta.jobId, {
    language: projectStore.meta.language || 'zh',
    mode: searchMode.value,
    query_text: searchText.value,
    query_reading: searchReading.value || null,
    is_ignore_punctuation: isIgnorePunctuation.value,
    limit: 1000,
  })

  const rows = resp.data?.data?.matches || []
  const idSet = new Set()
  const spanMap = new Map()
  const clusterMap = new Map()

  for (const row of rows) {
    const subtitle = projectStore.subtitles.find((s) => s.sentenceIndex === row.sentence_index)
    if (!subtitle) continue
    idSet.add(subtitle.id)
    if (!spanMap.has(subtitle.id)) spanMap.set(subtitle.id, [])
    spanMap.get(subtitle.id).push({
      start: row.char_start,
      end: row.char_end,
      readingKey: row.reading_key,
    })

    const clusterId = row.cluster_id || row.reading_key
    const readingLabel = row.reading_label || row.reading_key
    clusterMap.set(subtitle.id, {
      clusterId,
      readingLabel,
      color: pickClusterColor(clusterId),
      start: row.start ?? subtitle.start,
      end: row.end ?? subtitle.end,
    })
  }

  matchedSubtitleIds.value = idSet
  matchSpansMap.value = spanMap
  clusterMetaMap.value = clusterMap

  // 默认全选命中块
  selectedSubtitleIds.value = new Set(idSet)
}
```

## 10.3 全选/单选与批量替换

```javascript
function toggleSelectAll(checked) {

    selectedSubtitleIds.value = new Set(matchedSubtitleIds.value)
  } else {
    selectedSubtitleIds.value = new Set()
  }

function toggleRowSelection(subtitleId, checked) {
  const next = new Set(selectedSubtitleIds.value)
  if (checked) next.add(subtitleId)
  else next.delete(subtitleId)
  selectedSubtitleIds.value = next
}

async function applyBatchReplace() {
  const sentenceIndices = projectStore.subtitles
    .filter((s) => selectedSubtitleIds.value.has(s.id))
    .map((s) => s.sentenceIndex)
    .filter((v) => v !== undefined && v !== null)

  if (sentenceIndices.length === 0) return

  await transcriptionApi.batchReplaceHomophone(projectStore.meta.jobId, {
    language: projectStore.meta.language || 'zh',
    mode: searchMode.value,
    query_text: searchText.value,
    query_reading: searchReading.value || null,
    is_ignore_punctuation: isIgnorePunctuation.value,
    replacement_text: replaceText.value,
    selected_sentence_indices: sentenceIndices,
  })

  await executeSearch()
}
```

## 10.5 两种排序模式的核心渲染数据

```javascript
const groupedViewItems = computed(() => {
  if (sortMode.value !== 'grouped') return []

  const groups = new Map() // clusterId -> { clusterId, readingLabel, color, items }
  for (const subtitle of projectStore.subtitles) {
    if (!matchedSubtitleIds.value.has(subtitle.id)) continue
    const meta = clusterMetaMap.value.get(subtitle.id)
    if (!meta) continue

    if (!groups.has(meta.clusterId)) {
      groups.set(meta.clusterId, {
        clusterId: meta.clusterId,
        readingLabel: meta.readingLabel,
        color: meta.color,
        items: [],
      })
    }
    groups.get(meta.clusterId).items.push(subtitle)
  }

  const result = [...groups.values()]
  for (const group of result) {
    group.items.sort((a, b) => (a.start - b.start) || (a.end - b.end) || (a.sentenceIndex - b.sentenceIndex))
  }
  // 组排序：命中数降序，再按读音标签
  result.sort((a, b) => (b.items.length - a.items.length) || a.readingLabel.localeCompare(b.readingLabel))
  return result
})

const timelineViewItems = computed(() => {
  if (sortMode.value !== 'timeline') return []
  return projectStore.subtitles
    .filter((s) => matchedSubtitleIds.value.has(s.id))
    .slice()
    .sort((a, b) => (a.start - b.start) || (a.end - b.end) || (a.sentenceIndex - b.sentenceIndex))
})

function pickClusterColor(clusterId) {
  const palette = ['#3b82f6', '#ef4444', '#22c55e', '#a855f7', '#f59e0b', '#06b6d4']
  let hash = 0
  for (let i = 0; i < clusterId.length; i += 1) {
    hash = (hash * 31 + clusterId.charCodeAt(i)) >>> 0
  }
  return palette[hash % palette.length]
}
```

```javascript
const props = defineProps({
  subtitle: { type: Object, required: true },
  index: { type: Number, required: true },
  matchSpans: { type: Array, default: () => [] },
  isSelected: { type: Boolean, default: false },
  isSelectable: { type: Boolean, default: false },
})

function renderTextWithHighlight() {
  const text = props.subtitle.text || ''
  if (!props.matchSpans.length) return escapeHtml(text)

  let cursor = 0
  let html = ''
  const spans = [...props.matchSpans].sort((a, b) => a.start - b.start)
  for (const span of spans) {
    html += escapeHtml(text.slice(cursor, span.start))
    html += `<mark>${escapeHtml(text.slice(span.start, span.end))}</mark>`
    cursor = span.end
  }
  html += escapeHtml(text.slice(cursor))
  return html
}
```

## 11.1 功能定义

1. 设置页维护词条（增删改查）。

## 11.2 与推送延迟的权衡

### 默认策略（推荐）

* L7前同步替换，避免“先推送后闪烁修正”。
* 单 chunk 文本量通常较小，规则数可控时延迟可忽略。

### 兜底策略

* 若规则量极大导致延迟风险，则降级为 L7后异步补丁。
* 通过 `subtitle.edited` SSE 推送差量更新。

## 12. 不跨字幕匹配的实现约束

1. 分词入口函数签名固定为 `tokenize(sentence_text)`。
2. `index_chunk` 循环按 `sentence` 写入，不创建跨 sentence buffer。
3. 查找结果必须返回 `sentence_index`，前端只对该字幕高亮。
4. 批量替换入参仅接受 `selected_sentence_indices`。
