# AnchorFlux Lite v3.2.4 Release

本次发布以 `v3.2.4` 作为统一版本号，面向 **Lite 版本首次独立发布**


## Lite 功能特性

Lite 版本面向“已有字幕稿件的手动编辑”场景，支持以下能力：

1. **字幕导入**：支持将字幕文件导入为可编辑项目。
2. **完整字幕编辑**：包含常规文本编辑与时间轴编辑流程。
3. **字幕导出**：支持编辑完成后的字幕导出闭环。
4. **同音/近音批量处理**：支持同音相关检索与批量处理能力。
5. **媒体导入与预览**：支持关联媒体加载与预览。
6. **波形显示**：支持编辑过程中的波形可视化辅助。
7. **任务与项目管理**：支持编辑类项目管理与列表化操作。
