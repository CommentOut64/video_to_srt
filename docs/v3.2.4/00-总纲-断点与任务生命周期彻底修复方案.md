# 断点与任务生命周期彻底修复方案 - 总纲

> Type: Architecture | Status: Approved Draft
> Version: V3.2.0+dev.20260222.01
> Scope: 后端状态机、取消/删除收敛、断点恢复合并、前端实时同步、执行模型解耦
> 基于: `docs/v3.2.3/P0-L0-L8-断点与任务生命周期彻底修复方案.md` 优化拓展
> 评审: Codex 后端架构评估 + Claude 代码验证

## 1. 方案选择结论

经过多方案评估（A/B/C）和 Codex 后端架构交叉验证，最终采用 **方案 C+（混合式 + 契约收口）**：

- **核心策略**: 状态机作为**校验层**嵌入而非替代层，事件携带 `state_seq` 轻量有序性保障，合并器独立模块，每阶段灰度可交付。
- **不做**: 完整事件溯源（等多 Worker 再上）、执行模型进程级隔离（本轮仅做风险闸门）
- **关键洞察**: 当前 `completed/finished` 并存（`job_models.py:506`），多入口直写状态，是根本性风险源。

## 2. 问题代码实证

| 编号 | 问题 | 代码位置 | 影响 |
|------|------|----------|------|
| P1 | 状态迁移无白名单，`job.status` 直接赋值 | `job_queue_service.py` 全文 | 非法迁移无拦截 |
| P2 | `except Exception` 将取消/暂停误标为 `failed` | `orchestrator.py:295` | 终态语义错乱 |

| P4 | runtime_state.db 早返回导致 checkpoint.json 被忽略 | `orchestrator.py:461` | 转录细粒度丢失 |
| P5 | 前端未注册 `job_canceling/job_force_canceled` 信号 | `sseChannelManager.js:211` | 前端卡 canceling |
| P6 | 编辑器取消后立即断 SSE | `EditorView.vue:1506` | 收不到终态 |

## 3. 分阶段路线总览

```
Phase 0: 状态契约冻结 + 可观测性          ← P0 止血，不改业务行为
Phase 1: 取消/删除生命周期收敛            ← P0 用户最痛点
Phase 2: 断点恢复双源合并器              ← P1 控制面对齐
Phase 3: 执行模型风险闸门（非进程隔离）    ← P1 安全网
Phase 4: 前端状态投影统一                ← P1 前端收口
Phase 5: 测试矩阵与验收                 ← 回归保障
```

## 5. 灰度开关设计

每 Phase 独立开关 + 总开关：

```python
# backend/app/config/lifecycle_config.py
LIFECYCLE_V2_ENABLED = True          # 总开关
STATE_MACHINE_GUARD_ENABLED = True   # Phase 0: 状态机校验
CANCEL_V2_ENABLED = True             # Phase 1: 取消收敛
RESUME_MERGER_ENABLED = True         # Phase 2: 合并器
RUNNER_GATE_ENABLED = True           # Phase 3: 风险闸门
```

关闭任一开关即回退到旧实现路径。

## 6. PBT 不变量清单

| 编号 | 不变量 | 验证策略 |
|------|--------|---------|
| INV-1 | 合法迁移闭包：任何状态迁移必须在白名单内 | 随机状态 + 随机目标，校验迁移结果 |
| INV-2 | 终态吸收性：`finished/failed/canceled/force_canceled/removed` 不可逆 | 终态后尝试所有迁移，均被拒绝 |
| INV-3 | `state_seq` 严格单调递增 | 并发迁移后校验序号有序 |
| INV-4 | 取消/暂停绝不落入 `failed` | 注入 CancelledException/PausedException，校验终态 |
| INV-5 | 恢复后 `finalized_indices` 不倒退 | 暂停前后对比，恢复后集合只增不减 |
| INV-6 | 单执行槽唯一：`running_job_id` 任一时刻最多一个 | 并发取消+启动场景校验 |
| INV-7 | `canceling` 必须在超时阈值内收敛 | 注入超时场景，校验终态达成 |
