## 一、项目概述

### 1.1 项目简介

**Video-to-SRT GPU** 是一个基于 **WhisperX** 的高性能视频字幕生成工具，采用现代化前后端分离架构。该项目从简单的命令行脚本演进为功能完善的 Web 应用程序，支持 GPU 加速、实时进度监控和多任务并发处理。

### 1.2 核心特性

- ✅ **前后端分离架构** - Vue.js 3 + FastAPI，现代化 Web 应用
- ✅ **GPU 加速** - 支持 NVIDIA CUDA，转录速度提升 10 倍以上
- ✅ **实时进度监控** - 自适应轮询机制，实时反馈转录进度
- ✅ **智能模型预加载** - 启动时自动预加载常用模型，减少等待时间
- ✅ **CPU 亲和性优化** - 绑定特定 CPU 核心，提升处理效率
- ✅ **并发任务处理** - 支持多任务同时运行，充分利用硬件资源
- ✅ **智能音频分段** - 基于静音检测的智能分割，避免句子断裂
- ✅ **多格式支持** - 支持几乎所有主流视频/音频格式
- ✅ **用户友好界面** - 直观的 Web UI，拖拽上传，实时反馈

### 1.3 项目演进历史

| 版本 | 日期 | 主要变更 |
|------|------|---------|
| **v1.1.0** | 2024-06-18 | 初始版本 - 命令行界面，基础转录功能 |
| **v2.0.0** | 2025-08-18 | 重大架构升级 - 前后端分离、Web UI、模型预加载、并发处理、性能优化 |

## 五、核心功能实现

### 5.1 功能清单

| 功能模块 | 功能描述 | 实现位置 |
|---------|---------|---------|
| **文件管理** | 文件上传、列表展示、删除 | `frontend/src/components/file-management/FileSelector.vue` |
| **任务创建** | 为本地/上传文件创建转录任务 | `backend/app/processor.py:create_job()` |
| **任务启动** | 启动转录处理流程 | `backend/app/processor.py:start_job()` |
| **任务取消** | 取消正在运行的任务 | `backend/app/processor.py:cancel_job()` |
| **进度监控** | 实时查询任务进度和状态 | 前端轮询 + 后端状态管理 |
| **结果下载** | 下载生成的 SRT 字幕文件 | `GET /api/download/{job_id}` |
| **结果复制** | 复制字幕到视频源目录 | `POST /api/copy-result/{job_id}` |
| **硬件检测** | 检测 CPU、GPU、内存等信息 | `backend/app/services/hardware_service.py` |
| **模型预加载** | 启动时预加载常用模型 | `backend/app/services/model_preload_manager.py` |
| **缓存管理** | LRU 模型缓存，自动驱逐 | `ModelPreloadManager._evict_lru_model()` |
| **CPU 亲和性** | 绑定特定 CPU 核心 | `backend/app/processor.py:CPUAffinityManager` |
| **优化建议** | 根据硬件推荐最优配置 | `backend/app/services/hardware_service.py:CoreOptimizer` |

### 5.2 支持的文件格式

#### 输入格式

**视频格式**（15 种）:
```
.mp4, .avi, .mkv, .mov, .wmv, .flv, .webm, .m4v, .mpg, .mpeg, .3gp, .ts, .vob, .ogv, .divx
```

**音频格式**（9 种）:
```
.mp3, .wav, .flac, .aac, .ogg, .m4a, .wma, .opus, .ape
```

#### 输出格式

**字幕格式**: SRT (SubRip)
- 标准时间码格式: `HH:MM:SS,mmm`
- 支持句子级别时间戳（默认）
- 支持词级别时间戳（可选）

```python
def _extract_audio(self, input_file: str, audio_out: str) -> bool:
    """使用 FFmpeg 提取音频"""
    # 参数说明:
    # -y: 覆盖输出文件
    # -i: 输入文件
    # -vn: 不包含视频流
    # -ac 1: 单声道（Whisper 要求）
    # -ar 16000: 采样率 16kHz（Whisper 要求）
    # -acodec pcm_s16le: PCM 16位编码

    cmd = [
        'ffmpeg', '-y', '-i', input_file,
        '-vn',                    # 仅音频
        '-ac', '1',               # 单声道
        '-ar', '16000',           # 16kHz 采样率
        '-acodec', 'pcm_s16le',   # PCM 编码
        audio_out
    ]

    proc = subprocess.run(cmd, stdout=subprocess.PIPE, stderr=subprocess.PIPE)
    return proc.returncode == 0 and os.path.exists(audio_out)
```

#### 6.2.2 智能音频分段

**位置**: `backend/app/processor.py:386-414`

```python
def _split_audio(self, audio_path: str) -> List[Dict]:
    """基于静音检测的智能分段"""

    # 配置参数
    SEGMENT_LEN_MS = 60_000         # 60秒基础分段长度
    SILENCE_SEARCH_MS = 2_000       # 在分割点前 2 秒搜索静音
    MIN_SILENCE_LEN_MS = 300        # 最小静音长度 300ms
    SILENCE_THRESH_DBFS = -40       # 静音阈值 -40dB

    audio = AudioSegment.from_wav(audio_path)
    length = len(audio)
    segments = []
    pos = 0
    idx = 0

    while pos < length:
        end = min(pos + SEGMENT_LEN_MS, length)

        # 静音搜索优化
        if end < length and (end - pos) > SILENCE_SEARCH_MS:
            search_start = max(pos, end - SILENCE_SEARCH_MS)
            search_chunk = audio[search_start:end]

            try:
                # 检测静音点
                silences = silence.detect_silence(
                    search_chunk,
                    min_silence_len=MIN_SILENCE_LEN_MS,
                    silence_thresh=SILENCE_THRESH_DBFS
                )

                if silences:
                    # 在第一个静音点分割
                    silence_start = silences[0][0]
                    new_end = search_start + silence_start
                    if new_end - pos > MIN_SILENCE_LEN_MS:
                        end = new_end  # 优化分割点
            except Exception:
                pass  # 静音检测失败则使用默认分割点

        # 导出分段
        chunk = audio[pos:end]
        seg_file = os.path.join(os.path.dirname(audio_path), f'segment_{idx}.wav')
        chunk.export(seg_file, format='wav')

        segments.append({
            'file': seg_file,
            'start_ms': pos  # 记录起始位置（用于后续时间偏移校正）
        })

        pos = end
        idx += 1

    return segments
```

**优化效果**:
- ✅ 避免在说话中间分割，保持句子完整性
- ✅ 提高转录质量和字幕连贯性
- ✅ 减少时间戳对齐错误

#### 6.2.3 分段转录与对齐

**位置**: `backend/app/processor.py:455-485`

```python
def _transcribe_segment(self, seg: Dict, model, job: JobState, align_cache: Dict):
    """单个音频段的转录和对齐"""

    # 1. 加载音频
    audio = whisperx.load_audio(seg['file'])

    # 2. Whisper 转录（初步识别）
    rs = model.transcribe(
        audio,
        batch_size=job.settings.batch_size,
        verbose=False,
        language=job.language  # 如果已检测到语言则使用
    )

    if not rs or 'segments' not in rs:
        return None

    # 3. 语言检测（首次转录时）
    if not job.language and 'language' in rs:
        job.language = rs['language']

    lang = job.language or rs.get('language')

    # 4. 加载对齐模型（词级对齐）
    if lang not in align_cache:
        am, meta = self._get_align_model(lang, job.settings.device)
        align_cache[lang] = (am, meta)

    am, meta = align_cache[lang]

    # 5. 词级对齐（精确时间戳）
    aligned = whisperx.align(
        rs['segments'],  # 初步转录结果
        am,              # 对齐模型
        meta,            # 模型元数据
        audio,           # 原始音频
        job.settings.device
    )

    # 6. 时间偏移校正（关键！）
    # 因为每个段都是从 0 秒开始，需要加上段在整个音频中的起始偏移
    start_offset = seg['start_ms'] / 1000.0  # 毫秒转秒
    final = {'segments': []}

    if 'segments' in aligned:
        for s in aligned['segments']:
            if 'start' in s:
                s['start'] += start_offset
            if 'end' in s:
                s['end'] += start_offset
            final['segments'].append(s)

    # 词级时间戳也需要校正
    if 'word_segments' in aligned:
        final['word_segments'] = []
        for w in aligned['word_segments']:
            if 'start' in w:
                w['start'] += start_offset
            if 'end' in w:
                w['end'] += start_offset
            final['word_segments'].append(w)

    del audio  # 释放音频内存
    return final
```

#### 6.2.4 SRT 字幕生成

**位置**: `backend/app/processor.py:498-524`

```python
def _generate_srt(self, results: List[Dict], path: str, word_level: bool):
    """生成 SRT 格式字幕文件"""

    lines = []
    n = 1  # 字幕序号

    for r in results:
        if not r:
            continue

        entries = []

        # 词级时间戳模式
        if word_level and r.get('word_segments'):
            for w in r['word_segments']:
                if w.get('start') is not None and w.get('end') is not None:
                    txt = (w.get('word') or '').strip()
                    if txt:
                        entries.append({
                            'start': w['start'],
                            'end': w['end'],
                            'text': txt
                        })

        # 句子级时间戳模式（默认）
        elif r.get('segments'):
            for s in r['segments']:
                if s.get('start') is not None and s.get('end') is not None:
                    txt = (s.get('text') or '').strip()
                    if txt:
                        entries.append({
                            'start': s['start'],
                            'end': s['end'],
                            'text': txt
                        })

        # 写入 SRT 格式
        for e in entries:
            if e['end'] <= e['start']:
                continue  # 跳过无效时间戳

            lines.append(str(n))  # 序号
            lines.append(f"{self._format_ts(e['start'])} --> {self._format_ts(e['end'])}")  # 时间戳
            lines.append(e['text'])  # 字幕文本
            lines.append("")  # 空行
            n += 1

    # 写入文件
    with open(path, 'w', encoding='utf-8') as f:
        f.write('\n'.join(lines))

def _format_ts(self, sec: float) -> str:
    """格式化时间戳为 SRT 格式: HH:MM:SS,mmm"""
    if sec < 0:
        sec = 0

    ms = int(round(sec * 1000))
    h = ms // 3600000
    ms %= 3600000
    m = ms // 60000
    ms %= 60000
    s = ms // 1000
    ms %= 1000

    return f"{h:02}:{m:02}:{s:02},{ms:03}"
```

**SRT 格式示例**:
```
1
00:00:00,000 --> 00:00:03,520
这是第一句字幕

2
00:00:03,520 --> 00:00:07,120
这是第二句字幕
```

### 6.3 进度计算机制

**位置**: `backend/app/processor.py:282-301`

```python
# 阶段权重配置
PHASE_WEIGHTS = {
    "extract": 5,      # 音频提取占 5%
    "split": 10,       # 音频分段占 10%
    "transcribe": 80,  # 转录处理占 80%（主要耗时）
    "srt": 5           # SRT 生成占 5%
}

def _update_progress(self, job: JobState, phase: str, ratio: float, message: str = ''):
    """更新任务进度（加权计算）"""

    # 计算已完成阶段的累计权重
    done_weight = sum(PHASE_WEIGHTS[k] for k in PHASE_WEIGHTS if k < phase)

    # 当前阶段权重
    current_weight = PHASE_WEIGHTS[phase]

    # 总进度 = 已完成 + (当前阶段 × 当前进度)
    total_progress = done_weight + current_weight * ratio

    # 更新任务状态
    job.phase = phase
    job.progress = total_progress
    if message:
        job.message = message
```

**示例计算**:
```
假设当前在 transcribe 阶段，已处理 50% 的段：

done_weight = extract(5) + split(10) = 15
current_weight = transcribe(80)
ratio = 0.5

total_progress = 15 + 80 * 0.5 = 15 + 40 = 55%
```

```javascript
 * 轮询任务状态
 * - 正常情况: 1.5s 间隔
 * - 网络错误: 2.5s 间隔（自动重试）
 */
async function poll() {
  clearTimeout(pollTimer.value)

  if (!jobId.value) return

  try {
    const data = await TranscriptionService.getJobStatus(jobId.value)

    // 更新状态
    status.value = data.status
    progress.value = data.progress || 0
    statusText.value = data.message || data.status
    phase.value = data.phase || ""
    language.value = data.language || ""

      canRestart.value = true
      ElMessage.success('转录完成！')
      return  // 停止轮询
    }

    // 任务失败或取消
    if (status.value === "failed" || status.value === "canceled") {
      processing.value = false
      canRestart.value = true
      return  // 停止轮询
    }

    // 继续轮询
    pollTimer.value = setTimeout(poll, 1500)  // 1.5秒后再次查询

  } catch (e) {
    console.error('轮询失败:', e)
    // 网络错误: 延长间隔后重试
    pollTimer.value = setTimeout(poll, 2500)  // 2.5秒后重试
  }
}
```

### 8.2 模型预加载和缓存机制

#### 8.2.1 核心数据结构

**位置**: `backend/app/services/model_preload_manager.py`

```python
from dataclasses import dataclass
from collections import OrderedDict
import threading
import time

@dataclass
class ModelCacheInfo:
    """模型缓存信息"""
    model: Any                          # 模型对象
    key: Tuple[str, str, str]           # (model_name, compute_type, device)
    load_time: float                    # 加载耗时(秒)
    last_used: float                    # 最后使用时间戳
    memory_size: int                    # 估算内存占用(MB)

class ModelPreloadManager:
    def __init__(self):
        # LRU 缓存容器
        self._whisper_cache: OrderedDict[Tuple[str, str, str], ModelCacheInfo] = OrderedDict()
        self._align_cache: OrderedDict[str, Tuple[model, meta, last_used]] = OrderedDict()

        # 统一锁机制（避免多锁死锁）
        self._global_lock = threading.RLock()

        # 缓存配置
        self.max_cache_size = 3  # 最多缓存 3 个模型

        # 预加载状态
        self._preload_status = {
            "is_preloading": False,
            "progress": 0.0,
            "current_model": "",
            "loaded_models": [],
            "failed_models": [],
            "failed_attempts": 0,
            "max_retry_attempts": 3,
            "cache_version": time.time()  # 缓存版本号
        }

        # 内存监控器
        self.memory_monitor = MemoryMonitor()
```

#### 8.2.2 LRU 缓存策略

```python
def get_model(self, settings: JobSettings):
    """获取 Whisper 模型（LRU 缓存）"""
    key = (settings.model, settings.compute_type, settings.device)

    with self._global_lock:
        # 缓存命中
        if key in self._whisper_cache:
            info = self._whisper_cache[key]
            info.last_used = time.time()
            # 移到队列末尾（标记为最近使用）
            self._whisper_cache.move_to_end(key)
            return info.model

        # 缓存未命中，需要加载
        return self._load_whisper_model(settings)

def _load_whisper_model(self, settings: JobSettings):
    """加载 Whisper 模型"""
    with self._global_lock:
        # 检查缓存大小，驱逐 LRU 模型
        while len(self._whisper_cache) >= self.max_cache_size:
            self._evict_lru_model()

        # 检查内存是否充足
        if not self.memory_monitor.check_memory_available():
            raise RuntimeError("系统内存不足，无法加载模型")

        # 加载模型
        start_time = time.time()
        model = whisperx.load_model(
            settings.model,
            settings.device,
            compute_type=settings.compute_type
        )
        load_time = time.time() - start_time

        # 估算内存占用
        memory_size = self._estimate_model_size(settings.model)

        # 缓存模型
        info = ModelCacheInfo(
            model=model,
            key=(settings.model, settings.compute_type, settings.device),
            load_time=load_time,
            last_used=time.time(),
            memory_size=memory_size
        )
        self._whisper_cache[key] = info

        # 更新缓存版本号
        self._preload_status["cache_version"] = time.time()

        return model

def _evict_lru_model(self):
    """驱逐最久未使用的模型"""
    # OrderedDict 的第一个元素是最久未使用的
    oldest_key = next(iter(self._whisper_cache))
    info = self._whisper_cache.pop(oldest_key)

    # 释放模型内存
    del info.model
    gc.collect()
    if torch.cuda.is_available():
        torch.cuda.empty_cache()

    # 更新缓存版本号
    self._preload_status["cache_version"] = time.time()
```

#### 8.2.3 预加载幂等性实现

```python
async def preload_models(self, progress_callback=None):
    """预加载模型（幂等性保证）"""

    with self._global_lock:
        # 幂等性检查 - 防止重复预加载
        if self._preload_status["is_preloading"]:
            return {"success": True, "message": "预加载已在进行中"}

        # 检查失败次数
        if self._preload_status["failed_attempts"] >= self._preload_status["max_retry_attempts"]:
            return {"success": False, "message": "预加载失败次数过多，已停止"}

        # 设置预加载标志
        self._preload_status["is_preloading"] = True
        self._preload_status["progress"] = 0.0
        self._preload_status["current_model"] = ""

    try:
        for idx, model_name in enumerate(self.config.default_models):
            # 检查是否已缓存
            key = (model_name, self.config.compute_type, self.config.device)
            if key in self._whisper_cache:
                continue  # 跳过已加载的模型

            # 更新进度
            self._preload_status["current_model"] = model_name
            if progress_callback:
                progress_callback(idx / len(self.config.default_models), model_name)

            # 加载模型
            settings = JobSettings(
                model=model_name,
                compute_type=self.config.compute_type,
                device=self.config.device
            )
            model = self._load_whisper_model(settings)

            # 记录已加载
            self._preload_status["loaded_models"].append(model_name)

        # 预加载成功
        self._preload_status["progress"] = 1.0
        return {"success": True, "message": "预加载完成"}

    except Exception as e:
        # 预加载失败
        self._preload_status["failed_attempts"] += 1
        self._preload_status["failed_models"].append(self._preload_status["current_model"])
        return {"success": False, "message": f"预加载失败: {str(e)}"}

    finally:
        # 清除预加载标志
        self._preload_status["is_preloading"] = False
        self._preload_status["cache_version"] = time.time()
```

### 8.3 CPU 亲和性优化

#### 8.3.1 亲和性管理器

**位置**: `backend/app/processor.py:42-167`

```python
import psutil
from dataclasses import dataclass
from typing import List, Optional

@dataclass
class CPUAffinityConfig:
    """CPU 亲和性配置"""
    enabled: bool = False                     # 是否启用
    strategy: str = "auto"                    # 策略: auto/half/custom
    custom_cores: List[int] = field(default_factory=list)  # 自定义核心列表
    exclude_cores: List[int] = field(default_factory=list)  # 排除核心列表

class CPUAffinityManager:
    """CPU 核心绑定管理器"""

    def __init__(self):
        self.logger = logging.getLogger(__name__)
        self.original_affinity = None  # 保存原始设置

    def apply_cpu_affinity(self, config: CPUAffinityConfig) -> bool:
        """应用 CPU 亲和性设置"""
        try:
            # 1. 保存原始设置
            self.original_affinity = psutil.Process().cpu_affinity()

            # 2. 计算目标核心
            target_cores = self.calculate_optimal_cores(
                strategy=config.strategy,
                custom_cores=config.custom_cores,
                exclude_cores=config.exclude_cores
            )

            if not target_cores:
                return False

            # 3. 应用绑定
            psutil.Process().cpu_affinity(target_cores)
            self.logger.info(f"已应用 CPU 亲和性: {target_cores}")
            return True

        except Exception as e:
            self.logger.error(f"应用 CPU 亲和性失败: {e}")
            return False

    def restore_cpu_affinity(self) -> bool:
        """恢复原始 CPU 亲和性设置"""
        if self.original_affinity is None:
            return False

        try:
            psutil.Process().cpu_affinity(self.original_affinity)
            self.logger.info(f"已恢复 CPU 亲和性: {self.original_affinity}")
            return True
        except Exception as e:
            self.logger.error(f"恢复 CPU 亲和性失败: {e}")
            return False

    def calculate_optimal_cores(
        self,
        strategy: str = "auto",
        custom_cores: List[int] = None,
        exclude_cores: List[int] = None
    ) -> List[int]:
        """计算最优核心分配"""

        # 获取所有可用核心
        all_cores = list(range(psutil.cpu_count()))
        available_cores = [c for c in all_cores if c not in (exclude_cores or [])]
        cpu_count = len(available_cores)

        if strategy == "custom":
            # 用户自定义核心列表
            if not custom_cores:
                return []
            return [c for c in custom_cores if c in available_cores]

        elif strategy == "half":
            # 使用前 50% 的核心
            half_count = max(1, cpu_count // 2)
            return available_cores[:half_count]

        else:  # "auto" 默认策略
            if cpu_count <= 4:
                # 低端系统: 使用全部核心
                return available_cores
            elif cpu_count <= 8:
                # 中端系统: 留 1 个核心给系统
                return available_cores[:-1]
            else:
                # 高端多核: 使用前 75% 核心
                use_count = int(cpu_count * 0.75)
                return available_cores[:use_count]
```

```python
def _run_pipeline(self, job: JobState):
    """转录处理流程（应用 CPU 亲和性）"""

    # 任务开始前应用 CPU 亲和性
    cpu_applied = False
    if job.settings.cpu_affinity.enabled:
        cpu_applied = self.cpu_manager.apply_cpu_affinity(job.settings.cpu_affinity)
        if cpu_applied:
            self.logger.info(f"任务 {job.job_id} 已应用 CPU 亲和性设置")

    try:
        # 执行转录流程...
        self._extract_audio(...)
        self._split_audio(...)
        self._transcribe_segment(...)
        self._generate_srt(...)

    finally:
        # 任务结束后恢复 CPU 亲和性
        if cpu_applied:
            restored = self.cpu_manager.restore_cpu_affinity()
            if restored:
                self.logger.info(f"任务 {job.job_id} 已恢复 CPU 亲和性设置")

        # 清理内存
        gc.collect()
```

```python
class CoreHardwareDetector:
    """核心硬件检测器"""

    def detect(self) -> HardwareInfo:
        """并行检测各硬件组件"""
        gpu_info = self._detect_gpu()

        memory_info = self._detect_memory()

            gpu_memory_mb=gpu_info["gpu_memory_mb"],

            memory_available_mb=memory_info["memory_available_mb"],

            # Storage
            temp_space_available_gb=storage_info["temp_space_available_gb"]
        )

    def _detect_gpu(self) -> Dict:
        """GPU 检测"""
        if not torch.cuda.is_available():
            return {
                "cuda_available": False,
                "gpu_count": 0,
                "gpu_memory_mb": []
            }

        gpu_count = torch.cuda.device_count()
        gpu_memory_list = []
        gpu_names = []

        for i in range(gpu_count):
            device_props = torch.cuda.get_device_properties(i)
            memory_mb = device_props.total_memory // (1024 * 1024)
            gpu_name = device_props.name

            gpu_memory_list.append(memory_mb)
            gpu_names.append(gpu_name)

        return {
            "cuda_available": True,
            "gpu_count": gpu_count,
            "gpu_memory_mb": gpu_memory_list,
            "gpu_name": gpu_names[0] if gpu_names else "N/A",
            "cuda_version": torch.version.cuda or "N/A"
        }

    def _detect_cpu(self) -> Dict:
        """CPU 检测"""
        import platform

        return {
            "cpu_cores": psutil.cpu_count(logical=False),  # 物理核心
            "cpu_threads": psutil.cpu_count(logical=True),  # 逻辑线程
            "cpu_name": platform.processor() or "N/A"
        }
```
