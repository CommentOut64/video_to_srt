# V3.2.2-3 标点分句与 Bridge 融合指导

> Type: Architecture | Status: Active

## 1. Summary

* **Goal**: 统一 v3.2.2 与 v3.2.3 的最佳方案，形成“快流标点分句 → 语义缓冲 → Bridge 句群 → 慢流批次 → 对齐 → 推送”的闭环指导。
* **标点模型路由**: PunctuationService 按 LangID 路由分语言模型；未命中语言回退 ASR 默认标点透传（快流优先，可配慢流）。
* **最佳方案**: 快慢流共用分语言标点模型，Whisper 内置标点仅作兜底参考；最终断句由推送前的标点驱动切分层完成。
* **上下文组织**: Chunk 内短窗推理 + 尾部待定区回写；跨 Chunk 由语义缓冲衔接；说话人锚点或长停顿作为硬边界。
* **句群批次**: Bridge 按句群聚合 20-30s 或 6-10 句；触发条件含长停顿、说话人切换、硬上限、饥饿超时；允许 1-2s 音频重叠防断裂。
* **对齐策略**: 锚点对齐优先（快流词级时间戳、数字、专名）；差异过大时降级为时间对齐/编辑距离；失败回退快流草稿。
* **资源与时序**: CPU 负责 SenseVoice + 标点 + Bridge；GPU 仅慢流批次使用；Bridge 负责背压与解耦，避免 GPU 空转。
* **Fallback 总则**: 标点模型/Bridge/慢流/增量聚类/对齐均需可降级到 ASR 默认标点透传，必要时回退 DefaultSegmenter。

## 2. Diagram

* `预处理(VAD/分离/LangID/声纹)` -> `FastWorker` -> `PunctuationService(分语言)` -> `SemanticBuffer(边界待定区)` -> `Bridge(句群批次)` -> `SlowWorker(Whisper)` -> `去标点` -> `PunctuationService` -> `PunctuationArbiter` -> `DefaultAligner` -> `StreamingSubtitleManager(标点驱动切分)` -> `SSE 推送`
* `标点模型不可用/上下文不足` -> `DefaultSegmenter` -> `Bridge`; `Bridge 饥饿/超时` -> `强制 flush` -> `SlowWorker`; `SlowWorker 失败/超时` -> `快流草稿直出`
* `speaker_embedding` -> `增量聚类(可选)` -> `speaker_anchor` -> `SemanticBuffer/Bridge 强制边界`
* `CPU: SenseVoice + 标点 + Bridge` -> `GPU: Whisper 批次`（GPU 独占，CPU 并发）

## 3. Key Components

* `backend/app/pipelines/async_dual_pipeline.py`: 统一快慢流编排与背压；快流结果进入标点分句与语义缓冲；慢流从 Bridge 批次消费并触发对齐与推送。
* `backend/app/pipelines/workers/fast_worker.py`: 快流推理输出 words/language/metadata；不做分句；供标点模型、语义缓冲、锚点使用。
* `backend/app/pipelines/workers/slow_worker.py`: 慢流推理仅产出文本；失败时回退快流草稿；不负责标点与分句。
* `backend/app/services/punctuation/service.py`: 分语言标点路由与推理；CPU 默认；模型缺失/超时回退 ASR 默认标点或 DefaultSegmenter。
* `backend/app/services/punctuation/arbiter.py`: 标点仲裁与异常过滤；置信度不足时回退快流标点或无标点。
* `backend/app/services/punctuation/semantic_buffer.py`: 语义缓冲与边界回写；尾部待定区合并相邻 Chunk；上下文不足时延迟切分。
* `backend/app/services/segmentation/default_segmenter.py`: 标点缺失或上下文不足的降级分句；遵守最小句长与硬上限。
* `backend/app/services/alignment/default_aligner.py`: 锚点对齐优先；覆盖率低时降级时间对齐或编辑距离。
* `backend/app/services/streaming_subtitle.py`: 推送前最终断句入口；强标点必断、弱标点按长度阈值；过短片段合并。
* `backend/app/services/speaker_embedding_service.py`: 声纹向量提取与可选增量聚类锚点；不可用则仅用 VAD 停顿作为边界。
* `backend/app/services/audio/chunk_engine.py`: AudioChunk 携带 `language`/`speaker_embedding`，供标点路由与锚点。
* `backend/app/services/bridge/*`: Bridge 句群缓存与批次调度（新组件）；含饥饿保护、硬上限、说话人切换 flush；不可用时直接把语义缓冲输出给慢流。
* `backend/app/services/whisper_buffer_pool.py`: 慢流批次音频拼接与上下文维护；批次过短时补齐上下文。
