## 2. Overall Architecture

### 2.1 重构前（V3.1.2）

```
TranscriptionService
├─ if engine == "sensevoice": _sensevoice_process()
└─ if engine == "whisper": _whisper_process()

AsyncDualPipeline
├─ FastWorker
│  └─ SenseVoiceExecutor (硬编码)
├─ SlowWorker
│  └─ WhisperService (硬编码)
└─ AlignmentWorker
```

**问题**：
- 硬编码引擎选择（if-else）
- FastWorker/SlowWorker与具体模型紧耦合
- 无统一模型管理（散落在各Service）
- 新模型集成需修改多个位置

### 2.2 重构后（V3.2.0）

```
TranscriptionService
└─ ASREngineFactory.create(engine_name)
   ├─ SenseVoiceEngine
   ├─ WhisperEngine
   └─ DualStreamEngine (新增)

AsyncDualPipeline
├─ FastWorker (模型容器)
│  └─ draft_engine: ASREngine (可插拔)
├─ SlowWorker (模型容器)
│  └─ patch_engine: ASREngine (可插拔)
└─ AlignmentWorker

ModelManager V2 (统一管理)
├─ 模型下载/加载/卸载
├─ 显存预算池
└─ 版本控制
```

**改进**：
- 工厂模式 + 抽象接口
- Worker解耦，仅负责流水线逻辑
- 统一模型生命周期管理
- 插件化引擎生态

import numpy as np

class ConfidenceNormalizer:
    """置信度规范化器"""

    @staticmethod
    def normalize_sensevoice(logits: np.ndarray) -> float:
        """SenseVoice: CTC softmax均值"""
        from scipy.special import softmax
        confidence = np.mean(np.max(softmax(logits, axis=-1), axis=-1))
        return float(np.clip(confidence, 0.0, 1.0))

    @staticmethod
    def normalize_whisper(avg_logprob: float, no_speech_prob: float) -> float:
        """Whisper: logprob组合"""
        confidence = 1.0 + avg_logprob  # avg_logprob in [-1, 0]
        confidence = np.clip(confidence, 0.0, 1.0)
        confidence *= (1.0 - no_speech_prob)
        return float(confidence)
```

from backend.app.core.asr.engine import ASREngine
from backend.app.core.asr.models import ASRResult, Segment, WordTimestamp, ASRMetadata
from backend.app.core.asr.enums import ASRCapability, TimestampPrecision
from backend.app.services.sensevoice_onnx_service import get_sensevoice_service
from typing import List, Optional
import numpy as np

class SenseVoiceEngine(ASREngine):
    """SenseVoice ONNX引擎适配器"""

    def __init__(self, language: str = "auto"):
        self.service = get_sensevoice_service()
        self.language = language

    def get_capabilities(self) -> List[ASRCapability]:
        return [
            ASRCapability.WORD_TIMESTAMPS,
            ASRCapability.CONFIDENCE_SCORES,
            ASRCapability.LANGUAGE_DETECTION,
            ASRCapability.EMOTION_DETECTION,
            ASRCapability.EVENT_TAGGING,
        ]

    def get_timestamp_precision(self) -> TimestampPrecision:
        return TimestampPrecision.FRAME  # 60ms

    async def transcribe(
        self,
        audio: np.ndarray,
        language: Optional[str] = None,
        **kwargs
    ) -> ASRResult:
        """转录音频"""
        # 调用原有service
        raw_result = await self.service.transcribe_audio_array(
            audio,
            language=language or self.language
        )

        # 转换为统一格式
        words = [
            WordTimestamp(
                word=w["word"],
                start=w["start"],
                end=w["end"],
                confidence=w["confidence"],
                is_pseudo=w.get("is_pseudo", False)
            )
            for w in raw_result.get("words", [])
        ]

        segments = [Segment(
            start=words[0].start if words else 0.0,
            end=words[-1].end if words else 0.0,
            text=raw_result["text"],
            confidence=raw_result["confidence"],
            words=words
        )]

        return ASRResult(
            text=raw_result["text"],
            text_clean=raw_result.get("text_clean"),
            segments=segments,
            words=words,
            confidence=raw_result["confidence"],
            language=raw_result.get("language", "zh"),
            emotion=raw_result.get("emotion"),
            event_tags=raw_result.get("event", "").split() if raw_result.get("event") else None,
            metadata=ASRMetadata(
                engine="sensevoice",
                source="sensevoice",
                timestamp_precision=TimestampPrecision.FRAME,
                capabilities=self.get_capabilities(),
                # V3.2.0: 保留原始标签，用于下游处理（熔断、分句等）
                raw_tags={
                    "emotion_tag": raw_result.get("emotion"),
                    "event_tag": raw_result.get("event"),
                    "text_with_tags": raw_result.get("text_raw")  # 保留带标签的原始文本
                }
            )
        )
```

**⚠️ 重要提示**：

from backend.app.core.asr.engine import ASREngine
from backend.app.core.asr.models import ASRResult, Segment, WordTimestamp, ASRMetadata
from backend.app.core.asr.enums import ASRCapability, TimestampPrecision
from backend.app.core.asr.normalizer import ConfidenceNormalizer
from backend.app.services.whisper_service import get_whisper_service
from typing import List, Optional
import numpy as np

class WhisperEngine(ASREngine):
    """Faster-Whisper引擎适配器"""

    def __init__(self, model_size: str = "medium"):
        self.service = get_whisper_service()
        self.model_size = model_size

    def get_capabilities(self) -> List[ASRCapability]:
        return [
            ASRCapability.WORD_TIMESTAMPS,
            ASRCapability.CONFIDENCE_SCORES,
            ASRCapability.LANGUAGE_DETECTION,
        ]

    def get_timestamp_precision(self) -> TimestampPrecision:
        return TimestampPrecision.WORD  # ~100ms

    async def transcribe(
        self,
        audio: np.ndarray,
        language: Optional[str] = None,
        **kwargs
    ) -> ASRResult:
        """转录音频"""
        # 调用原有service
        raw_result = await self.service.transcribe(
            audio,
            language=language,
            word_timestamps=True
        )

        # 转换为统一格式
        segments = []
        all_words = []

        for seg in raw_result.get("segments", []):
            words = [
                WordTimestamp(
                    word=w["word"],
                    start=w["start"],
                    end=w["end"],
                    confidence=w.get("probability", 1.0),
                    is_pseudo=False
                )
                for w in seg.get("words", [])
            ]

            segments.append(Segment(
                start=seg["start"],
                end=seg["end"],
                text=seg["text"],
                confidence=ConfidenceNormalizer.normalize_whisper(
                    seg.get("avg_logprob", -1.0),
                    seg.get("no_speech_prob", 0.0)
                ),
                words=words
            ))

            all_words.extend(words)

        avg_confidence = np.mean([s.confidence for s in segments]) if segments else 0.0

        return ASRResult(
            text=raw_result["text"],
            segments=segments,
            words=all_words if all_words else None,
            confidence=float(avg_confidence),
            language=raw_result.get("language", "en"),
            metadata=ASRMetadata(
                engine="whisper",
                source="whisper",
                timestamp_precision=TimestampPrecision.WORD,
                capabilities=self.get_capabilities()
            )
        )
```

# backend/app/engines/dual_stream_engine.py
from backend.app.core.asr.engine import ASREngine
from backend.app.core.asr.models import ASRResult
from backend.app.core.asr.enums import ASRCapability, TimestampPrecision
from backend.app.engines.sensevoice_engine import SenseVoiceEngine
from backend.app.engines.whisper_engine import WhisperEngine
from typing import List, Optional
import numpy as np

class DualStreamEngine(ASREngine):
    """双流混合引擎：SenseVoice（时间戳） + Whisper（文本补刀）"""

    def __init__(
        self,
        draft_engine: Optional[ASREngine] = None,
        patch_engine: Optional[ASREngine] = None,
        patch_threshold: float = 0.7
    ):
        self.draft_engine = draft_engine or SenseVoiceEngine()
        self.patch_engine = patch_engine or WhisperEngine()
        self.patch_threshold = patch_threshold

    def get_capabilities(self) -> List[ASRCapability]:
        # 继承两者能力
        return list(set(
            self.draft_engine.get_capabilities() +
            self.patch_engine.get_capabilities()
        ))

    def get_timestamp_precision(self) -> TimestampPrecision:
        # 使用draft_engine（SenseVoice）的精度
        return self.draft_engine.get_timestamp_precision()

    async def transcribe(
        self,
        audio: np.ndarray,
        language: Optional[str] = None,
        enable_patch: bool = True,
        **kwargs
    ) -> ASRResult:
        """双流转录"""
        # Step 1: draft_engine生成草稿（时间戳权威）
        draft_result = await self.draft_engine.transcribe(audio, language)

        # Step 2: 判断是否需要补刀
        if enable_patch and draft_result.confidence < self.patch_threshold:
            # patch_engine补刀
            patch_result = await self.patch_engine.transcribe(audio, language)

            # 合并：使用draft的时间戳 + patch的文本
            draft_result.text = patch_result.text
            draft_result.metadata.source = "whisper_patch"

            # TODO: 更精细的段落级合并逻辑
            # 这里简化处理，实际需要segment级别的对齐

        return draft_result
```

    V3.2.0: 返回硬编码的ASRResult，用于快速测试流水线逻辑
    """

        self,
        response_text: str = "这是测试文本",
        confidence: float = 0.95,
        latency_ms: int = 100,  # 模拟延迟
        simulate_failure: bool = False

        self.confidence = confidence
        self.latency_ms = latency_ms

            ASRCapability.LANGUAGE_DETECTION,

        language: Optional[str] = None,
        **kwargs

        # 模拟延迟

            import asyncio

        # 模拟失败
        if self.simulate_failure:
            raise RuntimeError("DummyEngine simulated failure")

        # 生成假的字级时间戳

        current_time = 0.0
        for i, char in enumerate(self.response_text):
            words.append(WordTimestamp(
                word=char,
                start=current_time,
                end=current_time + 0.1,
                confidence=self.confidence,
                is_pseudo=True  # 标记为假数据

            current_time += 0.1

        segments = [Segment(
            start=0.0,
            end=current_time,
            text=self.response_text,
            confidence=self.confidence,
            words=words
        )]

            text=self.response_text,
            segments=segments,
            words=words,

# backend/app/pipelines/workers/fast_worker.py (重构后)
from backend.app.core.asr.engine import ASREngine
from backend.app.core.asr.models import ASRResult
from backend.app.models.audio_models import AudioChunk
from typing import Optional
import asyncio

class FastWorker:
    """快速推理Worker（模型容器）

    V3.2.0: 解耦为模型容器，draft_engine可插拔
    """

    def __init__(
        self,
        draft_engine: ASREngine,  # 依赖注入
        subtitle_manager,
        enable_fuse_breaker: bool = True,
        is_final_output: bool = False
    ):
        self.draft_engine = draft_engine
        self.subtitle_manager = subtitle_manager
        self.enable_fuse_breaker = enable_fuse_breaker
        self.is_final_output = is_final_output

    async def process_chunk(self, chunk: AudioChunk) -> dict:
        """处理单个音频块"""
        try:
            # Step 1: 调用draft_engine转录
            asr_result = await self.draft_engine.transcribe(
                chunk.audio,
                language=chunk.language
            )

            # Step 2: 分句（保留原有逻辑）
            sentences = self._split_sentences(asr_result)

            # Step 3: 熔断检查（可选）
            if self.enable_fuse_breaker:
                chunk = await self._check_fuse_breaker(chunk, asr_result)

            # Step 4: 推送字幕
            if self.is_final_output:
                await self.subtitle_manager.add_finalized_sentences(sentences)
            else:
                await self.subtitle_manager.add_draft_sentences(sentences)

            return {
                "success": True,
                "chunk": chunk,
                "sentences": sentences
            }

        except Exception as e:
            return {

from typing import Optional

class SlowWorker:
    """补刀推理Worker（模型容器）

    V3.2.0: 解耦为模型容器，patch_engine可插拔
    """

    def __init__(
        self,
        patch_engine: ASREngine,  # 依赖注入
        subtitle_manager,
        patch_threshold: float = 0.7
    ):
        self.patch_engine = patch_engine
        self.subtitle_manager = subtitle_manager
        self.patch_threshold = patch_threshold

    async def process_chunk(self, chunk_data: dict) -> dict:
        """处理单个块（补刀）"""
        chunk = chunk_data["chunk"]
        draft_sentences = chunk_data.get("sentences", [])

        try:
            # Step 1: 判断是否需要补刀
            need_patch = self._should_patch(draft_sentences)

            if not need_patch:
                return chunk_data  # 跳过补刀

            # Step 2: 调用patch_engine补刀
            patch_result = await self.patch_engine.transcribe(
                chunk.audio,
                language=chunk.language
            )

            # Step 3: 合并结果（使用draft时间戳 + patch文本）
            finalized_sentences = self._merge_results(
                draft_sentences,
                patch_result
            )

            # Step 4: 推送定稿
            await self.subtitle_manager.add_finalized_sentences(finalized_sentences)

            return {
                "success": True,
                "chunk": chunk,
                "sentences": finalized_sentences
            }

        except Exception as e:
            return {
                "success": False,
                "chunk": chunk,
                "error": str(e)
            }

        avg_confidence = sum(s.confidence for s in sentences) / len(sentences)

from backend.app.core.asr.engine import ASREngine
from typing import Dict, Type

class ASREngineFactory:
    """ASR引擎工厂"""

    _engines: Dict[str, Type[ASREngine]] = {}

    @classmethod
    def register(cls, name: str, engine_class: Type[ASREngine]):
        """注册引擎"""
        cls._engines[name] = engine_class

    @classmethod
    def create(cls, name: str, **kwargs) -> ASREngine:
        """创建引擎实例"""
        if name not in cls._engines:
            raise ValueError(f"Unknown engine: {name}. Available: {list(cls._engines.keys())}")

        engine_class = cls._engines[name]
        return engine_class(**kwargs)

    @classmethod
    def list_engines(cls) -> list:
        """列出所有注册的引擎"""
        return list(cls._engines.keys())

# 注册内置引擎
from backend.app.engines.sensevoice_engine import SenseVoiceEngine
from backend.app.engines.whisper_engine import WhisperEngine
from backend.app.engines.dual_stream_engine import DualStreamEngine

ASREngineFactory.register("whisper", WhisperEngine)
ASREngineFactory.register("dual_stream", DualStreamEngine)

## 5. Risk Management

### 5.1 风险识别

| 风险 | 概率 | 影响 | 缓解措施 |
|------|------|------|---------|
| **双流逻辑的移植难度** | 高 | 高 | metadata字段保留原始标签；充分测试熔断/分句逻辑 |
| 性能退化 | 中 | 高 | 性能基准测试，及时优化 |
| 兼容性问题 | 中 | 中 | 完善的向后兼容层 |
| 字幕质量下降 | 低 | 高 | 回归测试，对比v3.1.2 |
| 工期延误 | 中 | 中 | 预留缓冲时间，模块化开发 |
| 测试不充分 | 中 | 高 | 强制测试覆盖率要求 |

#### 风险详解：双流逻辑的移植难度

**问题描述**：

当前的 `AsyncDualPipeline` 和 Worker 层充斥着针对 SenseVoice 和 Whisper 特性的"胶水代码"，例如：
- SenseVoice的特殊标签处理（`<|BGM|>`、`<|HAPPY|>`、`<|APPLAUSE|>` 等）
- 基于事件标签的熔断决策逻辑
- Whisper的Prompt拼接和上下文共享
- 分句算法对CTC特性的依赖

**风险点**：

在将这些逻辑迁移到通用的 `ASRResult` 数据模型时，可能会遇到：
1. **信息丢失**：转换层过度清洗，丢失原始标签信息
2. **接口不足**：`ASRResult` 的标准字段不够表达引擎特有信息
3. **逻辑耦合**：熔断决策、分句优化等下游逻辑依赖引擎特定字段

**缓解措施**：

1. **充分利用metadata字段**（Phase 2）：
   ```python
   metadata=ASRMetadata(
       engine="sensevoice",
       # 保留所有原始信息
       raw_tags={
           "emotion_tag": "<|HAPPY|>",
           "event_tag": "<|BGM|>",
           "text_with_tags": "完整的<|BGM|>带标签<|HAPPY|>文本"
       }
   )
   ```

2. **建立标签映射层**（Phase 3）：
   ```python
   class TagExtractor:
       """从metadata提取引擎特定标签"""
       @staticmethod
       def extract_sensevoice_events(metadata: ASRMetadata) -> List[str]:
           return metadata.raw_tags.get("event_tag", "").split()
   ```

3. **充分测试下游逻辑**（Phase 4）：
   - [ ] 熔断决策逻辑与新接口的集成测试
   - [ ] 分句算法与新接口的集成测试
   - [ ] 对比v3.1.2的熔断/分句行为，确保一致性

**验证标准**：
- [ ] 所有SenseVoice原始标签可从ASRResult中恢复
- [ ] 熔断决策逻辑功能不变
- [ ] 分句准确率与v3.1.2相同（误差<2%）

**Risk 1: 双流逻辑的移植难度 (Phase 3.2)**

- 目前的 `AsyncDualPipeline` 里充斥着针对 SenseVoice 和 Whisper 特性的“胶水代码”（例如：如何处理 SenseVoice 的特殊标签，如何拼接 Whisper 的 Prompt）。
- **挑战**：将这些逻辑迁移到通用的 `DualStreamEngine` 或新流水线时，可能会发现通用的 `ASRResult` 字段不够用。
- **建议**：在实现 `SenseVoiceEngine` 时，务必充分利用 `metadata` 字典字段，把 `<|BGM|>`、`<|HAPPY|>` 等原始标签透传出来，不要在转换层丢失信息。

#### 增加 "DummyEngine" (哑引擎) 用于测试

在 Phase 2 (引擎实现) 中，除了实现 `SenseVoiceEngine` 和 `WhisperEngine`，建议增加一个 `DummyEngine`。

- **作用**：它不加载任何模型，只返回硬编码的 `ASRResult`。
- **价值**：它可以让你在不依赖庞大 PyTorch 环境的情况下，快速测试 `FastWorker`、`SlowWorker` 和前端 UI 的交互逻辑。这将极大加速 Phase 3 的开发。
