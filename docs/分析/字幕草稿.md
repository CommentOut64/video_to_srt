（本视频字幕完全使用**AnchorFlux**生成和编辑）
大家好，AnchorFlux v3.1点0测试版已经发布。这是up独立开发、可在本地运行的视频字幕AI生成+快速编辑器，采用SenseVoice + Whisper的快慢双流架构，目前支持中文和英文转录。

先说一下配置要求。
目前只支持Windows 10或11，电脑内存至少8 G B ，推荐16 GB以上。
C P U 的要求，主流的 CPU 大部分足够，最低要求是英特尔 i5 10400F或者AMD 锐龙5  3600以上。
G P U 的要求，如果你是核显、AMD独显或者英特尔独显，目前只能使用极速模式，因为Whisper在CPU上跑不动并且强依赖于哭打；如果你有10系即以上的英伟达独立显卡并且显存在4GB以上就可使用所有模式，前提是你需要将显卡驱动更新到最新版本。

## 下载和初始化

接下来介绍 下仔  方式和初始化。
推荐使用整合包，下仔链接已经放在简介中。其中后缀为 Base 的整合包是不包含任何 Whisper 模型的，在需要 Whisper 模型时会自动下仔，但是下仔速度比较慢；后缀为 Full 的由于自带了 Whisper medium模型，所以压缩包达到了4.4 G B ，这个整合包下仔下来是可以直接使用所有模式的。
整合包下仔完成后，解压到一个目录，然后 双击 一键启动，程序会自动配置环境并开始下仔依赖，需要保持网络通畅。如果下仔失败，可以切换网络试试。
依赖下仔一般需要10至15分钟，请耐心等待。
重要提醒：程序运行时请勿关闭任何命令行窗口，就是这两个黑色的窗口，如果不小心关了可以双击一键启动来重新启动，但之前的任务进度可能会丢失。
现在依赖已经下仔完成了，程序会自动启动并打开浏览器页面，如果你看到和我一样的界面说明已经成功启动了。
整合包里自带一个很小的测试视频，可以使用它跑一遍完整流程来验证所有配置是否正确。 

## 创建任务

现在，我们来创建一个任务。 
首先，点击上传视频。程序提供了两种上传视频的方式，在直接上传 中，可以直接将视频拖动到框内，或者点击选择文件；在本地目录选择 中，程序会读取位于项目目录下的 input 文件夹，可以点击打开 input 目录快速打开。比较大的视频或者比较多的视频，推荐使用从本地目录选择，会快很多。当程序运行时往 input 添加视频后，可能需要手动刷新一下。
我们可以选中多个视频同时上传，这样就会同时创建多个任务然后逐个运行，并 且 使用相同的转录设置。添加 任务 的先后顺序是固定的，后续可以在 任务监控中调整。
接下来，我们点击转录设置展开，可以看到三个预设和三个模块。up建议优先使用下面的三个模块进行自定义组合。
简单介绍一下，第一个模块 前处理，就是在进行字幕生成前，进行人声分离，这样可以去除背景的音乐或者噪音，让字幕更加准确。
选择直通，是完全不进行人声分离。
选择智能分诊，会自动判断，只 分离带有明显背景声的片段。
极致分离，则会对整条音频进行人声分离。
如果你的视频的音频很干净，只有人声，就选直通；如果有背景音乐，选择智能分诊就足够了，即便漏掉了几个片段，后续还会有 熔断机制进行兜底。极致分离由于很慢不推荐。

---

  第 二 个 模块 转录核心，需要根据你的硬件能力和需求来调整。
如果你没有英伟达的独立显卡，目前就只能选择极速，这在 多 数 情况下已经足够了，并且生成速度会非常快。
智能补刀的意思是，程序只会对 SenseVoice 置信度低的片段进行 Whisper 二次转录，简单说就是，只有 SenseVoice 不太确定的片段，才会送给 Whisper 让它做一个深入的判断。
双流精校是， SenseVoice 和 Whisper 同时运行并对音频全程进行转录，速度很慢，适用于需要非常准确的字幕的场景。
额 外需要注意的是，因为 Whisper medium对于中文的 支 持不太好，所以如果你的视频是以中文为主，请无脑选择极速模式。
如果你的视频是以英文 为主，推荐使用 智能分诊 加上 智能补刀。
转 录 设置完成后，点击创建任务， 任 务就会自动启动。

## 任务队列和任务进度

接下来介绍任务队列和任务进度系统。
创建任务后，可以点击任务卡片进入编辑器界面。
点击右上角的任务监控，就能看到任务队列中的所有任务以及他们的进度。点击最近完成就能看到已经完成的任务。
任务卡片的右侧有暂停按钮和取消按钮。
排队中的任务可以通过按住左侧拖动图标  拖动来调整顺序。
也支持点击任务卡片直接跳转到该任务的编辑器界面。
我们回到编辑器界面，可以看到，界面顶部有一个双层的进度条，这就是 当前任务的实时进度。其中蓝色的S代表 SenseVoice 的转录进度，绿色的W代表 Whisper 的转录进度。
如果你使用的是极速模式，那么绿色的进度就会一直停在0%，这是正常现象不必担心。
把鼠标移到进度条上，会出现两个按钮，分别是暂停任务和取消任务。点击暂停后可能会发现进度条依然在 增长，这是因为需要等待正在处理的片段完成后才能暂停。
取消任务会将该任务的所有数据删除，包括已经生成的字幕，所以要小心 使用。

## 字幕编辑 
接下来介绍字幕编辑系统。

我们先来简单认识一下编辑界面。

左侧最大的部分是预览窗口，可以直接看到加了字幕后的视频效果。按住 Ctrl键 可以拖动字幕框，左上角是切换方向，右上角是重置位置。
预览窗口下面是视频控制栏，支持快进快退、拖动进度、音量调节和倍速播放。

再下面是最重要的波形窗口。
最下层的波形图就是视频音频的可视化，可以很容易的区分有声部分和静音部分。
我们还可以看到很多蓝色的框框，这就是每一条字幕的显示时间范围，非常直观。
波形窗口最特色的地方是它是上下分离的。我们把鼠标移动到上半部分，就可以点击移动光标。鼠标处在光标上时也可以点击拖动光标。
当我们把鼠标移动到下半部分，就可以操控这些蓝色框框。比如整体移动，让整条字幕在时间上提前或者推迟。
也可以拖动左侧边缘改变字幕出现的时间点，拖动右侧边缘改变字幕消失的时间点。
波形图支持 拖动 或者 滚动，支持放大缩小，这样  就可以做一些精细的修改。

---

回到主界面，界面的右侧是完整的字幕列表，支持改变宽度。每个字幕块都标注了起止时间点、持续时间和字幕文本，点击字幕文本可以直接修改，如果修改不满意，可以撤销。
我们还能看到有些字幕带有小标签，这就是该字幕的置信度，置信度越低就说明越有可能出错。还有一些词被高亮了，说明这些词在生成时，模型不确定是否正确，提醒我们重点关注。

接下来介绍一下最常使用的几种操作。
第一，修改字幕文本。直接在字幕列表中修改就可以了，会自动保存。
第二，修改字幕时间。可以直接修改字幕块中的时间戳，也可以在波形窗口中拖动蓝色框进行修改。
第三，增加，减少字幕。可以点击最上面的加号在列表结尾新建一个空白字幕，也可以使用在前面插入，和在后面插入，新字幕的时间戳会自动取相邻字幕的 边界值。如果要删除一个字幕，点击叉号，再次点击确认，就可以删除该字幕。
第四，拆分字幕。由于模型更擅长生成比较长的字幕，可以看到大部分字幕都比较长，有些甚至包含多句 话。这时候，可以在文本光标处，右键，从此处切分，就能够将一个字幕从光标处 拆分成两个字幕，注意标点符号其实也是占有一定时间的。
拆分后的时间戳已经尽可能保持准确，但还是会有误差，需要 手动调整。
 此外，在波形图上右键也可以从光标处拆分。

---

最后，介绍一下字幕导出。点击右上角的导出，选择导出的格式，就会自动下仔字幕文件，你做的所有修改都会自动应用，非常方便。

以上就是对于项目主要功能的 介绍，但是还有几个重要的问题没有回答。
问题一：字幕准确率如何？
这里up要说明一下衡量字幕准确率的两个指标，字词准确率和断句准确率。字词准确率衡量的是字幕文本的准确率，错字错词多，准确率就低； 断句准确率衡量的是字幕之间 断开位置 的准确率，字幕过度切分或者没有及时切分，准确率就低。
经过实测 在智能分诊+智能补刀 的模式下，英文的字词准确率能够达到85%，但断句准确率确实不高，这也是当前架构的一个缺陷。
未来会使用标点符号小模型 优化分句算法和对齐算法，可以期待一下。
还要说明，音频本身的质量，背景音的干扰，语言的选择都会影响准确率，所以建议使用干净、高质量的人声音频，也可以开启预处理中的智能分诊来优化。

问题二：出现了 bug 怎么办？
当前版本是测试版本，即使 up做了很多测试但依然会出现很多奇奇怪怪的 bug。
绝大多数问题可以通过重启程序 或者重新创建任务解决。
如果 bug 依然存在，可以私信我并提供项目目录 logs 文件夹中最新的几个日志文件，或者在 github 上提交 issue 。up会尽力去修复的。
问题三：未来项目的发展方向？
计划引入标点符号模型，引入大模型 做语义校对和翻译，添加烧录字幕的功能，这样就可以覆盖视频字幕制作的全流程。
问题四：是否可以换成其他模型，是否支持参数自定义？
很遗憾，当前版本由于时间不足只集成了 SenseVoice 和 Whisper medium，理论上 Whisper 的所有模型都可以用来替换，但是考虑到 large 模型有更高的显存要求并且提升没有特别大，所以只采用了 medium 模型。至于其他的 ASR 模型，因为所需的参数和模型特性各不相同，很难在单一架构中集成，所以也暂时不考虑。
对于是否支持参数自定义，其实up在开发每个功能时都提前考虑到了，也保留了相对完整的配置接口，但是要整理所有的配置参数是一个大工程，时间有限也暂时搁置了，所以，目前版本是不支持自定义参数的。
