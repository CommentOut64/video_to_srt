## Report (调查结果)

### 一、视觉设计系统分析

#### 1.1 专业深色主题

**设计灵感**: VS Code Dark+, GitHub Dark Dimmed, Figma Dark

**核心背景色层次**:
```scss
$bg-base: #0d1117;        // 最深背景
$bg-primary: #161b22;     // 主背景
$bg-secondary: #21262d;   // 次级背景/卡片
$bg-tertiary: #30363d;    // 三级背景/悬停
$bg-elevated: #2d333b;    // 浮层背景
```

**亮点**:
- **五层背景渐进**: 从最深的基底到浮层,形成清晰的视觉层次
- **柔和对比度**: 文本色从主要(#e6edf3)到禁用(#484f58),避免刺眼
- **精心调配的色板**: 主色(蓝#58a6ff)、成功(绿#3fb950)、警告(橙#d29922)、危险(红#f85149)、紫色(#a371f7)、粉色(#db61a2)
- **专业波形配色**: 波形#58a6ff、进度#238636、光标#f85149、区域半透明叠加

#### 1.2 阴影与圆角系统

**阴影层次**:
```scss
--shadow-sm: 0 1px 2px rgba(0, 0, 0, 0.4);
--shadow-md: 0 3px 6px rgba(0, 0, 0, 0.3), 0 1px 3px rgba(0, 0, 0, 0.4);
--shadow-lg: 0 8px 24px rgba(0, 0, 0, 0.4), 0 3px 8px rgba(0, 0, 0, 0.3);
--shadow-xl: 0 16px 48px rgba(0, 0, 0, 0.5), 0 6px 16px rgba(0, 0, 0, 0.4);
--shadow-glow: 0 0 16px rgba(88, 166, 255, 0.15);  // 发光效果
```

**圆角系统**:
```scss
--radius-xs: 3px;   // 极小圆角
--radius-sm: 6px;   // 小圆角
--radius-md: 8px;   // 中等圆角
--radius-lg: 12px;  // 大圆角
--radius-xl: 16px;  // 超大圆角
--radius-full: 9999px;  // 完全圆形
```

**亮点**:
- 阴影采用双层叠加,模拟真实光影
- 圆角系统从3px到16px,适配不同尺寸组件
- `shadow-glow` 用于主色元素的发光效果,增强视觉焦点

#### 1.3 过渡与动画系统

**过渡速度**:
```scss
--transition-fast: 0.1s ease;    // 快速响应(按钮悬停)
--transition-normal: 0.2s ease;  // 正常过渡(颜色变化)
--transition-slow: 0.3s ease;    // 缓慢过渡(布局变化)
```

**关键动画**:
- **呼吸灯边框**: 当前编辑任务卡片3秒周期呼吸动画,边框从透明到#028AC5
- **字幕切分动画**: TransitionGroup实现300ms淡出上移+淡入下滑
- **加载旋转**: 1秒周期旋转动画,用于加载状态
- **草稿生成指示器**: 小型旋转spinner + 斜体"生成中"文字

### 二、交互体验优化详解

#### 2.1 拖拽功能实现

**侧边栏宽度拖拽** (`EditorView.vue`):
- **拖拽手柄**: 4px宽度分隔条,悬停/激活时变为主色
- **宽度约束**: 最小280px,最大600px
- **用户偏好**: 自动保存到localStorage `editor-sidebar-width`
- **鼠标样式**: `cursor: col-resize`

**字幕块时间拖拽** (`WaveformTimeline/index.vue`):
- **Region拖拽**: 基于WaveSurfer.js Regions插件
- **实时同步**: `region-updated` 事件同步到projectStore
- **视觉反馈**: 区域进入时颜色加深(0.25 → 0.4 alpha)

**进度条拖拽** (`PlaybackControls/index.vue`):
- **拖拽状态管理**: PlaybackManager统一管理isDragging状态
- **视频就绪拦截**: 通过inject获取isVideoReady,视频未加载时阻止拖拽
- **防止文本选择**: `e.preventDefault()` 阻止拖拽时的文本选择干扰

#### 2.2 键盘快捷键支持

**播放控制**:
- 空格: 播放/暂停
- 左/右方向键: 逐帧后退/前进(1/30秒)
- J/L: 快退/快进5秒
- Home/End: 跳转到开始/结束

**编辑操作**:
- Ctrl+Z: 撤销
- Ctrl+Shift+Z: 重做
- Ctrl+S: 保存项目
- Ctrl+E: 导出字幕

**视图控制**:
- +/-: 波形缩放
- Ctrl+0: 波形适应屏幕
- Ctrl+Up/Down: 字体大小调整

**亮点**: 快捷键由 `useShortcuts` hook统一管理,避免组件间冲突

#### 2.3 右键菜单设计

**ContextMenu组件特点**:
- **Teleport传送**: 挂载到body,避免z-index冲突
- **位置自适应**: 检测视口边界,自动调整位置防止溢出
- **ESC关闭**: 监听键盘事件,ESC键快速关闭
- **点击外部关闭**: 全局监听click和contextmenu事件
- **过渡动画**: 150ms淡入淡出 + 缩放(0.95 → 1)

**应用场景**:
1. **波形图右键切分**: 在字幕时间范围内右键,显示"从此处切分"
2. **字幕列表编辑模式切分**: 在textarea中右键,从光标位置切分

#### 2.4 加载状态反馈

**波形图加载**:
- **加载遮罩**: 半透明背景 + 旋转spinner + "加载波形中..."文字
- **错误重试**: 显示错误图标、错误信息、重试按钮
- **自动重试**: 最大重试3次,达到后启动定时检查

**视频加载**:
- **渐进式加载**: 优先360p预览,后台转码720p代理
- **转码进度**: 实时显示转码百分比
- **状态提示**: "正在分析"、"转码中"、"转码完成"

**任务加载**:
- **骨架屏**: 未使用(直接显示加载遮罩)
- **加载文案**: "加载项目中..."简洁明了

#### 2.5 错误提示的友好性

**表单验证**:
- Element Plus原生validation,红色边框+错误文字
- 输入框focus时显示帮助文字

**操作确认**:
- 删除任务: "确定要删除这个任务吗?"原生confirm
- 取消转录: "确定要取消当前转录任务吗?"原生confirm
- 删除字幕: 双击确认机制(第一次点击变红色垃圾桶,第二次确认删除)

**错误状态显示**:
- **任务失败卡片**: 红色图标+错误信息
- **加载失败遮罩**: 错误图标+错误描述+重试按钮+返回链接
- **404任务**: "任务不存在(已被删除),本地记录已清理",2秒后自动跳转

### 三、实时反馈机制深度分析

#### 3.1 进度条的多层级设计

**主进度条** (`EditorHeader.vue`):
- **单层进度条**: 0-100%总体进度
- **阶段标签**: 显示当前阶段(音频提取/频谱分析/VAD切分/转录/校对/翻译)
- **阶段颜色**: 通过PHASE_CONFIG动态设置背景色和文字颜色

**双流进度条** (V3.5+):
- **草稿流进度**: 灰色渐变(#6b7280 → #9ca3af),显示SenseVoice快流进度
- **定稿流进度**: 蓝绿渐变(#028AC5 → #3fb950),显示Whisper慢流进度
- **进度条高度**: 6px(从4px增加),确保视觉清晰度
- **数据来源**: SSE事件 `progress.overall` 中的 `detail.fast` 和 `detail.slow`

**任务卡片进度**:
- **轨道背景**: `var(--border-muted)`
- **填充颜色**: `var(--primary)`渐变
- **百分比文字**: 11px等宽字体,右对齐

#### 3.2 状态指示器(成功/警告/错误)

**字幕置信度指示器**:
- **置信度徽章**:
  - 良好(≥80%): 绿色背景+绿色文字
  - 警告(60-80%): 橙色背景+橙色文字
  - 危险(<60%): 红色背景+红色文字
- **边框颜色警告**:
  - 低置信度: 橙色边框 + 橙色背景(6%透明度)
  - 高困惑度: 深橙色边框
  - 同时存在: 红色边框(2px加粗)

**草稿状态指示器**:
- **灰色边框**: rgba(128, 128, 128, 0.2)
- **旋转spinner**: 10px直径,2px边框,1秒旋转周期
- **斜体文字**: "生成中"灰色斜体
- **锁定样式**: cursor: wait,不可编辑

**任务状态颜色**:
- 创建: 灰色
- 队列: 黄色
- 处理中: 蓝色
- 完成: 绿色
- 失败: 红色
- 暂停: 橙色
- 取消: 灰色

#### 3.3 实时字幕流的视觉呈现

**草稿字幕渲染**:
- **即时插入**: 调用 `projectStore.appendOrUpdateDraft(chunkIndex, sentenceData)`
- **灰色斜体**: 区分草稿与定稿
- **不可编辑**: isDraft=true锁定编辑

**定稿字幕替换**:
- **无动画替换**: 直接调用 `projectStore.replaceChunk(chunkIndex, formattedSentences)`
- **颜色恢复**: 从灰色斜体变为正常文本
- **启用编辑**: isDraft=false解锁编辑

**字级高亮显示**:
- **临界低置信度(<50%)**: 黄色背景(25%透明度) + 黄色下划线(2px)
- **严重低置信度(<30%)**: 红色背景(25%透明度) + 红色下划线(2px) + 加粗
- **智能空格**: 中文字符间不加空格,英文单词间加空格,标点符号前不加空格

#### 3.4 置信度警告的颜色编码

**三级警告系统**:

| 警告类型 | 边框颜色 | 背景色 | 序号颜色 | 触发条件 |
|---------|---------|-------|---------|---------|
| low_confidence | #d29922(橙) | rgba(210,153,34,0.06) | #d29922(橙) | 转录置信度<阈值 |
| high_perplexity | #e67700(深橙) | rgba(230,119,0,0.06) | #e67700(深橙) | LLM困惑度>阈值 |
| both | #f85149(红) | rgba(248,81,73,0.08) | #f85149(红) | 同时满足两个条件 |

**警告横幅**:
- 橙色左边框(3px) + 浅橙色背景
- 11px文字: "低置信度,建议人工审核"

### 五、性能感知优化技巧

#### 5.1 虚拟滚动的视觉连续性

**当前状态**: 字幕列表未使用虚拟滚动

**波形图滚动优化**:
- **自定义滚动条**: 隐藏WaveSurfer原生滚动条,自定义滚动条UI
- **RAF节流**: 滚动事件使用requestAnimationFrame节流,避免频繁DOM查询
- **DOM查询缓存**: 缓存 `scrollWidth`、`clientWidth`、`maxScrollLeft`

#### 5.2 骨架屏和占位符

**当前状态**: 未使用骨架屏,直接显示加载遮罩

**占位符应用**:
- 视频区域: 黑色背景 + 居中加载提示
- 波形区域: 灰色背景 + 旋转spinner + 文字
- 任务卡片: 无骨架屏,直接渲染

**改进建议**:
- 添加字幕列表骨架屏(灰色矩形块闪烁)
- 添加任务卡片骨架屏(渐变动画)

#### 5.3 懒加载的反馈

**波形峰值懒加载**:
- **动态采样**: `/api/media/{jobId}/peaks?samples=0` 让后端自动计算
- **失败重试**: 最大重试3次
- **定时检查**: 重试失败后启动定时polling检查peaks是否生成

**视频懒加载**:
- **渐进式策略**: 360p预览 → 720p代理 → 原始视频
- **转码进度**: SSE实时推送转码进度

#### 5.4 防抖节流的用户感知

**防抖应用**:
- **任务操作**: 暂停/恢复按钮2秒防抖,防止频繁切换
- **字幕保存**: 300ms防抖,避免频繁写入

**节流应用**:
- **滚动事件**: RAF节流,16.67ms一次
- **时间同步**: 最小100ms间隔,避免频繁更新

**用户感知**:
- 防抖时显示 ElMessage.warning('操作过于频繁,请稍后再试')
- 节流时无提示,静默优化

### 六、细节打磨亮点展示

#### 6.1 微动画的应用场景

**呼吸灯动画** (3秒周期):
- **当前编辑任务卡片**: 边框从透明到#028AC5,带阴影
- **当前播放字幕**: 边框从透明到绿色,带阴影
- **实现**: CSS `@keyframes breathing-border` + `animation: breathing-border 3s ease-in-out infinite`

**切分动画** (300ms):
- **旧字幕淡出**: opacity 1→0, translateY 0→20px
- **新字幕淡入**: opacity 0→1, translateY -20px→0
- **实现**: Vue 3 `<TransitionGroup name="subtitle-list">`

**右键菜单动画** (150ms):
- **淡入**: opacity 0→1, scale 0.95→1
- **淡出**: 反向
- **实现**: `<Transition name="context-menu">`

**加载旋转** (1秒周期):
- **spinner**: border-top-color旋转360度
- **实现**: CSS `@keyframes spin` + `animation: spin 1s linear infinite`

#### 6.2 边距和间距的一致性

**间距系统**:
```scss
$spacing-xs: 4px;   // 极小间距(图标与文字)
$spacing-sm: 8px;   // 小间距(按钮组)
$spacing-md: 16px;  // 中等间距(卡片内边距)
$spacing-lg: 24px;  // 大间距(区块间距)
$spacing-xl: 32px;  // 超大间距(页面边距)
$spacing-xxl: 48px; // 特大间距(空状态)
```

**应用一致性**:
- 卡片内边距: 统一12px
- 按钮间距: 统一8px gap
- 表单字段间距: 统一16px margin-bottom
- 区块间距: 统一24px

#### 6.3 字体和排版的选择

**字体栈**:
- **西文系统字体**: -apple-system, BlinkMacSystemFont, "Segoe UI"
- **中文无衬线**: "Noto Sans", Helvetica, Arial, sans-serif
- **Emoji支持**: "Apple Color Emoji", "Segoe UI Emoji"
- **等宽字体**: "JetBrains Mono", "SF Mono", Monaco, Consolas

**字号系统**:
```scss

$font-size-sm: 12px;   // 正文(字幕文本)
$font-size-md: 14px;   // 标准(按钮/输入框)
$font-size-lg: 16px;   // 标题
$font-size-xl: 20px;   // 大标题
$font-size-xxl: 24px;  // 超大标题
```

**排版规范**:
- 行高: 1.5倍(正文)、1.4倍(字幕文本)
- 字重: 400(常规)、600(标题/徽章)
- 字间距: 正常(未调整)

#### 6.4 图标系统的使用

**图标来源**: 内联SVG(Material Design Icons风格)

**图标尺寸规范**:
- 小图标: 14px×14px (时间箭头)
- 标准图标: 16px×16px (按钮图标)
- 大图标: 48px×48px (空状态)
- 超大图标: 64px×64px (错误页面)

**图标颜色**:
- 默认: `currentColor` 继承文字颜色
- 悬停: 变为 `var(--text-normal)`
- 激活: 变为 `var(--primary)`

**语义化使用**:
- 播放: 三角形
- 暂停: 双竖条
- 快进/快退: 双三角形
- 成功: 对勾
- 错误: 感叹号圆圈
- 删除: X叉号/垃圾桶

## Conclusions (关键事实总结)

### 视觉设计系统

1. **五层背景渐进系统**提供清晰的视觉层次,从最深的基底(#0d1117)到浮层背景(#2d333b)
2. **柔和对比度文本系统**避免刺眼,文本色从主要(#e6edf3)到禁用(#484f58)
3. **双层叠加阴影**模拟真实光影,增强深度感知
4. **专业波形配色**采用音频编辑器标准(波形蓝/进度绿/光标红)

### 交互体验优化

5. **侧边栏宽度拖拽**支持280-600px范围,自动保存用户偏好
6. **视频就绪拦截机制**在视频未加载时阻止播放/跳转操作,防止误操作
7. **双击确认删除**机制避免误删,第一次点击变红色,第二次确认
8. **键盘快捷键统一管理**由useShortcuts hook管理,避免组件间冲突

### 实时反馈机制

9. **双流进度条**独立显示SenseVoice快流(灰色)和Whisper慢流(蓝绿渐变)
10. **三级置信度警告**通过颜色编码(橙/深橙/红)区分严重程度
11. **字级高亮显示**临界低置信度(<50%)黄色下划线,严重低置信度(<30%)红色下划线+加粗
12. **呼吸灯边框动画**用于当前编辑任务和当前播放字幕,3秒周期

### 可访问性和易用性

13. **Tooltip统一规范**500ms延迟显示,位置自适应,内容简洁
14. **自定义右键菜单**Teleport传送到body,位置自适应,ESC快速关闭
15. **表单验证友好提示**红色边框高亮+错误信息显示
16. **无障碍支持基本缺失**,需添加ARIA标签和键盘导航优化

### 性能感知优化

17. **RAF节流滚动事件**避免频繁DOM查询,16.67ms一次
18. **DOM查询缓存**缓存scrollWidth/clientWidth/maxScrollLeft
19. **防抖控制任务操作**2秒防抖防止频繁切换暂停/恢复
20. **渐进式视频加载**360p预览→720p代理→原始视频,SSE实时推送转码进度

### 细节打磨

21. **切分动画300ms**旧字幕向上淡出,新字幕从上方滑入
22. **间距系统一致性**从4px到48px六级间距,卡片内边距统一12px
23. **等宽字体用于时间戳**JetBrains Mono增强数字可读性
24. **内联SVG图标**Material Design风格,14-64px四级尺寸规范

## Relations (组件关系说明)

### 视觉设计层

- `_variables.scss` 定义全局CSS变量 → `main.scss` 导入并应用到全局样式 → 所有组件通过 `var(--变量名)` 引用

### 状态管理层

- `App.vue` 监听全局SSE → `unifiedTaskStore` 同步任务状态 → `TaskCard.vue` 显示任务卡片
- `EditorView.vue` 监听任务SSE → `progressStore` 管理进度状态 → `EditorHeader.vue` 显示进度条
- `EditorView.vue` 处理字幕SSE → `projectStore` 管理字幕数据 → `SubtitleList` 渲染字幕列表

### 交互控制层

- `PlaybackManager` 单例管理播放状态 → `PlaybackControls` 控制播放 → `VideoStage` 播放视频 → `WaveformTimeline` 同步波形
- `EditorView.vue` provide上下文 → `PlaybackControls` inject isVideoReady → 拦截播放操作

### 组件通信层

- `SubtitleItem` 右键菜单 → `ContextMenu` 显示菜单 → emit select事件 → `projectStore.splitSubtitle()` 执行切分
- `WaveformTimeline` Region点击 → `PlaybackManager.seekTo()` → `VideoStage` 跳转 + `projectStore` 更新时间

### 实时更新层

- 后端推送SSE → `sseChannelManager` 分发事件 → `EditorView` 处理事件 → `projectStore` 更新数据 → 组件自动重新渲染
