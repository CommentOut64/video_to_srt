## 九、关键决策记录

### 1. Bug 关键词优化

**问题**: 初始关键词"investigation"导致 90+ 文档误分类为 Bug 调查

**决策**: 收紧关键词范围，使用更具体的术语：
- 保留: bug, issue, fix, error, missing, loss, leak
- 移除: investigation, 调查（过于宽泛）

**结果**: 降至 43 个准确识别的 Bug 调查报告

### 2. 格式问题优先级

**问题**: 发现 178 个格式问题，无法一次性修复

**决策**: 建立优先级体系
- P1（立即修复）: 相对路径（影响功能）
- P3（可选优化）: 长段落、深层标题（不影响功能）

**结果**: 仅修复 P1 问题，P3 问题留待后续按需处理

### 3. 重复文档检查范围

**决策**: 全面检查所有核心目录（architecture, overview, guides, reference）
